# Интерфейс HighGrade

Один пакет React/TypeScript/Vite. Приложение читает реальный локальный API через NativeWorkspace/NativeDocument; Storybook показывает общие компоненты на изолированных данных. Визуальные демонстрации SpecWorkspace сохраняют согласованные состояния. SpecEditor сохраняет поля через локальный CAS, DecisionDialog записывает решения по видимой редакции.

Этот README владеет устройством и правилами разработки frontend. Запуск, наблюдаемое поведение и контракт локального API принадлежат [docs/UI.md](../docs/UI.md); при изменении этих частей сверяйте документ с реальным UI и включайте правки в то же изменение. При подготовке выпуска сверяйте его запись. Проверки и команды остаются в [DEVELOPMENT](../docs/DEVELOPMENT.md#интерфейс-и-storybook), упаковка выпуска — в [BUILD](../docs/BUILD.md#ресурсы-интерфейса).

## Где что находится

| Каталог | Ответственность |
|---|---|
| src/app | Вход приложения и начальная страница каталога |
| src/api | Типы канонического документа, HTTP и диагностические ошибки |
| src/components/ui | Полученные CLI shadcn/ui примитивы на Radix. Общие изменения вида — через токены |
| src/components | Иконки и основы каталога; здесь место переиспользуемым составным компонентам |
| src/features/specs | Экран спецификации, локальные взаимодействия, явно демонстрационные fixtures и истории |
| src/styles/theme.css | Manrope, цвет, отступы, фокус, адаптивность; единственный владелец оформления |
| src/assets | Локальный шрифт, трассированный логотип и исходники иконок |
| .storybook | Порядок разделов, общие параметры и бренд каталога |
| tests | Playwright: поведение, доступность, ресурсы и визуальные снимки |

Добавляя компонент, сначала используйте существующий примитив. Историю `*.stories.tsx` держите рядом; добавьте русское описание назначения, controls существенных свойств и состояния. Экраны получают предметные данные через props. Не создавайте второй набор токенов или вычисление готовности на клиенте. Storybook не обращается к реальному проекту и не отправляет записи в backend.

Навигация: **Начало → Основы → Компоненты → Спецификации → Сценарии**. Fixtures имеют ID HG-DEMO и постоянную пометку демонстрации. «Сохранить» меняет только состояние React; это не доказательство сохранения спецификации на диске.

Источники/лицензии — [ресурсы](licenses/README.md). Исходное оформление — [референсы](../docs/proposals/specification-ui/design-refinement.md).

`dist/` и `storybook-static/` — воспроизводимые сборки. `scripts/bundle.mjs` перед сборкой синхронизирует public с исходниками assets/licenses; затем пишет манифест отпечатков, CLI/API и источников. Не редактируйте производные копии public вручную. build.rs встраивает dist в CLI; сервер проверяет его до открытия порта. Без полного комплекта ui откажется запускаться. Штатный кандидат собирается из точного Git SHA по [BUILD](../docs/BUILD.md#ресурсы-интерфейса).
