# Спецификации проекта

Данные принадлежат проекту и сохраняются при удалении High Grade.
`catalog.json` — версия и счётчик; `requirements/` — действующие требования;
`changes/<ID>/spec.json` — изменение, `results.json` — проверки и решения.
Записывайте через инструмент с проверкой ожидаемого хеша. При наличии
`transaction.json` чтение заблокировано до явного `spec-recover`.
