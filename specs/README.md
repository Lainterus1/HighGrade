# Спецификации проекта

Данные принадлежат проекту и сохраняются при удалении High Grade.
`catalog.json` — версия и счётчик; `requirements/` — действующие требования;
`changes/<ID>/spec.json` — изменение, `results.json` — проверки и решения.
Записывайте через инструмент с проверкой ожидаемого хеша. При наличии
`transaction.json` чтение заблокировано до явного `spec-recover`.

Действующее поведение описано в `requirements/<ID>.json` без обращения к прежним
источникам. `changes/<ID>/spec.json` и `results.json` сохраняют историю изменения
и проверок, но не заменяют текст действующего требования. Архивные материалы не
определяют текущее поведение. Статус `in_progress`
означает, что проверка поведения ещё не подтверждена; решение человека
фиксируется отдельно и не выводится из наличия требования.
