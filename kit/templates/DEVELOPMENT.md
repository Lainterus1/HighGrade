# Подготовка и проверки

Укажи реальные команды установки зависимостей, запуска, штатных тестов и диагностики. Для каждой команды обозначь необходимое окружение и ожидаемый результат. Для поддерживаемых отчётов укажи команду получения исходного машинного результата, путь к нему и способ сверить ID сценариев с исполненными тестами. Для ручных сценариев укажи, где хранится запись фактического упражнения; текст инструкции не равен его результату. Команды тестов запускаются напрямую; High Grade только читает их отчёты.
