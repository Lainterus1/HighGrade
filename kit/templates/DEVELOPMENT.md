# Подготовка и проверки

Укажи реальные команды установки зависимостей, запуска и диагностики. Для проверок раздели фокусные тесты, обязательные полные барьеры, сборку и получение сценарных доказательств. Для каждой команды назови покрытие, условие запуска, необходимое окружение, ожидаемый результат и путь к исходному отчёту. Если два запуска покрывают одни тесты, объясни добавочное покрытие либо выбери один основной маршрут; отдельное обязательное покрытие не пропускай.

Для поддерживаемых отчётов укажи способ сверить ID сценариев с исполненными тестами. Для ручных сценариев укажи место записи фактического упражнения; текст инструкции не равен результату. Штатные тесты запускаются напрямую либо явной выборкой `spec-run` через настроенные `runners.json`/`checks`. Чтение каталога не запускает код. Для упражнения задай подготовку состояния, действие, наблюдение, значимые входы, формат отчёта и тайм-аут. Ручной способ остаётся допустимым.
