# High Grade project route

Use the corresponding global High Grade skills for initialization, task development, specification, execution, authorized delivery, state review and tooling update. Read local decisions in [project instruction](.highgrade/project/INSTRUCTIONS.md), then only needed current sources. If absent, propose highgrade-init before applying High Grade rules. Do not automatically call highgrade-clear after ordinary work. Local skills complement common skills. Preserve accepted responsibilities; show new unresolved conflicts before dependent actions.

Select the route through active Delivery task: changed requirements use spec; technical work/fixes under unchanged contracts use work. Use highgrade-planner for sequential dependent tasks/specifications. Planner owns Goal authority and continuation; reuse the user's known mode choice. Plan-only permits no implementation. Risk determines checks/review, not a specification ID.
