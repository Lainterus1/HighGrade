# <Название проекта>

Назначение, пользователи и границы проекта. Краткий вход в документацию: [правила агента](AGENTS.md), [устройство](docs/ARCHITECTURE.md), [инженерные соглашения](docs/ENGINEERING.md), [команды](docs/DEVELOPMENT.md). Новые изменения поведения ведутся в JSON-спецификации High Grade; прежние источники сохраняются по проектной инструкции.

Укажи проектный каталог спецификаций и команду выборочного spec-list/spec-read. Объясни, что эти данные принадлежат проекту и сохраняются при смене workflow.
