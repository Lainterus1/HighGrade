# High Grade init

Это общий навык уровня пользователя. Определи профиль пользователя по расположению файла `<профиль>/.agents/skills/highgrade-init/SKILL.md`. Прочитай `<профиль>/.highgrade/global/active.json`, проверь выбранную поставку через CLI из неё, затем прочитай только `rules.md` и `procedures/init.md` той же поставки, а также нужные материалы по их ссылкам. Корень целевого проекта задан пользователем или текущим workspace; не выводи его из пути навыка. В подключённом проекте прочитай `.highgrade/project/INSTRUCTIONS.md`; при init его отсутствие ожидаемо. Если глобальная поставка отсутствует или повреждена, сообщи точное состояние. Сохраняй полномочия пользователя и посторонние изменения.
