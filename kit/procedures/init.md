# Инициализация проекта

Прочитай действующие AGENTS, README, архитектуру, инженерные правила, команды, OpenSpec, локальные навыки, тесты и применимые файлы проекта. Для существующего проекта проведи полный аудит по `references/audit.md` и read-only `inventory`; перечисли непрочитанное и неизвестное. Для нового проекта выясни назначение, критерии успеха, риски, ограничения и пожелания автора. Задавай только вопросы, на которые ещё нет ответа.

Сопоставь документы с пятью основными ролями; полезную структуру сохраняй, если автор не выбрал согласованную реорганизацию. Для каждого местного навыка установи повод вызова, вход, выход и владельца действия. При пересечении с общим навыком High Grade явно покажи конфликт и варианты: использовать общий, скорректировать местный или оставить местный как выбранный активный маршрут. Не устанавливай два конкурирующих активных пути молча.

Предложи `.highgrade/project/INSTRUCTIONS.md`, короткую ссылку из AGENTS, маршрут OpenSpec, проектные команды, бюджеты контекста и один план адаптации. Начальный init завершается согласованным планом. Изменения выполняются только в разрешённой области; техническое подключение и пользовательская приёмка различаются. Общие навыки, CLI и процедуры в проект не копируются.
