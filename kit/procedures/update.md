# Обновление общей поставки

Работай только по явному запросу обновить High Grade. Выбери конкретный источник; не ищи latest и не сканируй проекты. Для Git зафиксируй выбранный SHA, создай его изолированную копию через archive/worktree и собери CLI в ней по [справочнику](../references/cli.md). Грязное рабочее дерево само не становится кандидатом; запрос на его использование требует отдельно обозначенного состава и неизменяемого снимка, без автоматического коммита. Для готового пакета зафиксируй происхождение и отпечатки, используй поставляемый с ним CLI; одна совпадающая версия бинарника не доказывает его происхождение. Если источник неоднозначен, уточни только этот выбор.

До переключения проверь текущую установку её CLI, сохрани его заведомо рабочую копию вне каталогов выпуска для диагностики сбоя. Зафиксируй прежний release ID. Проверь кандидат: манифест, хеши, версию CLI, совместимость стабильных маршрутизирующих SKILL.md и изменения общих правил. Выполни preview через CLI кандидата, запиши candidate_sha256 и после смыслового обзора примени --apply true --candidate-sha256 <тот же отпечаток>. Изменение кандидата требует нового preview. После применения проверь global-status; ошибка или unknown не означают успех. Материалы выпуска неизменяемы; после успешной проверки CLI удаляет собственные файлы неактивных выпусков, сохраняя чужие с предупреждением.

## Повтор и ошибки

- GlobalSameRelease запрещает повторное переключение, но само по себе не доказывает равенство состава. При успешном global-status сравни SHA256 кандидатного manifest.json с manifest_sha256 проверенного <профиль>/.highgrade/global/releases/<active>/journal.json и SHA256 кандидатного CLI с установленным highgrade.exe. Сам manifest.json в установленный выпуск не копируется. Проверенный манифест связывает остальные материалы; status проверяет целостность установки. Только совпадение даёт ответ «этот состав уже установлен», без apply. Различие — конфликт неизменяемого release ID; не перезаписывай выпуск и не переименовывай его ради обхода. Нужен отдельно подготовленный новый выпуск. Недоступное сравнение оставь unknown.
- При любом сбое сохрани исходную ошибку и немедленно проверь global-status сохранённым прежним CLI. Код предусматривает восстановление после ошибки postcheck, однако восстановление тоже может не выполниться. Сообщи фактически подтверждённый активный выпуск и незавершённую очистку отдельно от ошибки обновления. Если status не проходит, состояние не подтверждено: останови дальнейшие изменения установки и предложи восстановление по наблюдаемой ошибке; не редактируй указатель и не запускай очистку вслепую. Успешный откат не заявляй только по тексту инструкции.

Проектные инструкции автоматически не переписываются. Применяй [контракт совместимости](../references/cli.md#совместимость-проекта): схема отдельно от смысла, принятые исключения сохраняются. При следующем входе в проект проверь совместимость; сложный конфликт разбирает highgrade-clear. Кратко сообщи исходный и фактический выпуск, результат проверки, ошибку и незавершённую очистку, если они есть; приёмку проектов не подразумевай.
