# Обновление общей поставки

Работай только по явному запросу обновить High Grade. Выбери конкретный исходный каталог и кандидатный исполняемый файл; не ищи latest и не сканируй проекты. До переключения проверь манифест, хеши, версию CLI, совместимость стабильных маршрутизирующих SKILL.md, изменения общих правил и текущее состояние. Сначала выполни preview командой `global-update`, запиши `candidate_sha256` из preview и после смыслового обзора примени `--apply true --candidate-sha256 <тот же отпечаток>`; если кандидат изменился, начни новый preview. Новые материалы неизменяемы, активный указатель переключается после проверок, прежняя поставка сохраняется для отката.

Проектные инструкции автоматически не переписываются. При следующем входе в проект выполняется лёгкая проверка совместимости; сложный конфликт разбирает `highgrade-clear`. Сообщи установленную версию, результаты проверок и состояние отката отдельно от приёмки проектов.
