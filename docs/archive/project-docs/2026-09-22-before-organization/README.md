# MyCodex

MyCodex — место разработки переносимого workflow Codex и собственных инструментов. Целевые проекты используют выбранную копию workflow; отсюда они не управляются.

Состояние: начальная организация исходников и сопровождения. Workflow спроектирован, но его навыки, CLI, установщик и хуки ещё не реализованы. MyCodex уже следует согласованным правилам документации и сохранения доказательств; полное применение собственных инструментов требует их реализации и испытания.
