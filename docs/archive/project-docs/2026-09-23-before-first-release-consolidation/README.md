# High Grade

Репозиторий: [Lainterus1/HighGrade](https://github.com/Lainterus1/HighGrade). Название принято 2026-09-23; прежнее название MyCodex сохраняется в исторических материалах.

High Grade — место разработки переносимого workflow Codex и собственных плагинов. Он не управляет другими проектами: выбранная поставка применяется и адаптируется внутри каждого целевого проекта.

**Сейчас:** согласованы принципы workflow, организованы документы и сохранены исходники двух плагинов. Универсальные навыки, CLI, установщик и хуки не реализованы. Текущая работа — обсуждение состава и назначения инструментов, без написания программ.

## Вход по задаче

| Нужно | Читать |
|---|---|
| Работать в этом проекте | [AGENTS](AGENTS.md), затем необходимые документы по ссылкам |
| Понять, что уже принято | [Требования workflow](docs/workflow/SPECIFICATION.md) и [контекст и сопровождение](docs/workflow/CONTEXT.md) |
| Обсудить будущие инструменты | [Набор и назначение](docs/proposals/TOOLING.md); [техническая проработка](docs/proposals/technical-design.md) только при необходимости |
| Понять существующее устройство | [ARCHITECTURE](docs/ARCHITECTURE.md) |
| Изменять и проверять компоненты | [ENGINEERING](docs/ENGINEERING.md), [DEVELOPMENT](docs/DEVELOPMENT.md) |
| Найти SVG и Code Health Audit | [Плагины](plugins/README.md) |
| Восстановить причины и историю | [Исследование BDD](docs/research/bdd-workflow.md), [архив](docs/archive/README.md) |
| Проверить результат организации | [Ревью](docs/reviews/project-organization-review.md) |

High Grade уже использует собственные правила документации, архива и доказательств. Это не означает, что полный workflow технически работает. Исходники плагинов поддерживаются здесь; установленные копии Codex пока остаются прежними.

**Следующее действие:** обсудить роли и границы инструментов из TOOLING. Создание прототипов и программ сейчас не поручено.
