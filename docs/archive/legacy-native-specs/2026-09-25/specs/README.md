# Спецификации проекта

Данные принадлежат проекту и сохраняются при удалении High Grade.
`catalog.json` — версия и счётчик; `requirements/` — действующие требования;
`changes/<ID>/spec.json` — изменение, `results.json` — проверки и решения.
Записывайте через инструмент с проверкой ожидаемого хеша. При наличии
`transaction.json` чтение заблокировано до явного `spec-recover`.

Прежние требования Проекта распределены по [карте переноса](../docs/imports/openspec-migration.json).
Проверенные импортированные контракты закреплены в `requirements/` через
`spec-transfer`; `changes/` и `imports` сохраняют историю и происхождение.
Их наличие в действующем каталоге не означает проверку поведения или
решение человека. Открытые сценарии видны как `in_progress` до доказательств.
