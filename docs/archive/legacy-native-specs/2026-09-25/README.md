# Снимок до канонизации требований

Это исторический снимок промежуточного нативного каталога Проекта. `specs/` содержит действующие требования и не загружает этот архив при чтении, проверке или trace.

`specs/catalog.json`, `specs/requirements/` и сохранённые `specs/changes/` отражают состояние до канонизации; [file-hashes.json](file-hashes.json) закрепляет их байты. [mapping.json](mapping.json) связывает прежние ID с действующими и перечисляет выведенные правила/сценарии. [Аудит требований](audit.md) объясняет решения, [сверка сценариев](scenario-audit.md) фиксирует судьбу каждого, а [локальное ревью](review.md) — найденные и исправленные дефекты. Исходный OpenSpec и карта первого переноса находятся в соседнем [архиве](../../legacy-openspec/).

Исторические `results.json` и ревью относятся к прежним редакциям; они не засчитываются автоматически новым ID. Текущее отсутствие доказательства обозначено как `in_progress`, человеческое решение — `pending`. Открытое HG-0006 сохранено только в действующем каталоге и не входит в этот снимок.
