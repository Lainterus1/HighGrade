## ADDED Requirements

### Requirement: [HG-PD-R09] Воспроизводимый и диагностируемый Update

Update SHALL фиксировать источник кандидата и соответствующий ему CLI, работать с неизменяемой копией, различать совпадающий установленный состав и конфликт одного release ID, а после ошибки проверять фактическое состояние без безусловного обещания восстановления.

#### Scenario: [HG-PD-S14] Источник и успешное обновление

**Проверка:** `ручная`

- **WHEN** разрешено обновление из выбранного Git SHA или переданного готового пакета
- **THEN** агент фиксирует SHA либо происхождение и отпечаток пакета, использует соответствующий CLI, связывает preview/apply одним отпечатком и подтверждает активный выпуск

#### Scenario: [HG-PD-S15] Повтор выпуска

**Проверка:** `ручная`

- **WHEN** CLI возвращает GlobalSameRelease
- **THEN** совпадающие манифест и CLI при исправной установке дают ответ «уже установлено» без записи; различие состава либо недостаток доказательств не объявляются успехом, ID самовольно не меняется

#### Scenario: [HG-PD-S16] Сбой обновления

**Проверка:** `ручная`

- **WHEN** обновление завершилось ошибкой
- **THEN** агент проверяет status прежним заведомо рабочим CLI, сообщает наблюдаемую версию или неизвестное состояние, сохраняет данные ошибки и не продолжает изменяющие действия при неподтверждённом восстановлении
