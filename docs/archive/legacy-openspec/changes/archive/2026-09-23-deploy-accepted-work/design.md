# Design

## Маршрут выпуска

Явный вызов `$deploy` означает принятие указанной задачи к выпуску и полномочие на её коммит, push и документированную активацию. Агент сначала сверяет источник задач, завершённые проверки и ревью, определяет точные файлы и участки изменений, состояние ветки, remote и способ активации. Неопределённость состава или цели разрешается до мутаций. Посторонние изменения и чужой индекс Git сохраняются.

Действующие документы и ссылки отражают принятый результат. Для отклонённых гипотез остаются причина и существенное доказательство в архиве; удаляются только проверенные одноразовые результаты без значимых входящих ссылок. Неудача текущей проверки возвращает задачу в работу и не считается отклонённой гипотезой автоматически.

После проверки полного staged diff, секретов, происхождения и штатных тестов агент создаёт локальный коммит выбранного состава, проверяет возможность обычного push и отправляет его. Удалённый SHA сверяется с локальным. Затем применяется только документированная процедура активации проекта из артефакта, связанного с опубликованным SHA; для сборки используется изолированная копия этого коммита, если рабочее дерево может содержать другие изменения. Если после push активация не прошла, публикация остаётся зафиксированной, а статус активации сообщается отдельно; скрытый force push или отмена опубликованного коммита не выполняются.

## Общая поставка High Grade

`deploy` становится седьмым пользовательским маршрутизатором. `highgrade-update` и команда `global-update` остаются. Новая сборка CLI должна проверять прежнюю поставку из шести навыков и новую из семи, устанавливать новый маршрутизатор без изменения прежних, а при откате убирать его и уметь восстановить из неизменяемой копии релиза. Прерванная установка может оставить маршрут видимым на старом релизе; сам маршрут обязан обнаружить отсутствие активной процедуры и не выполнять выпуск. Инструкция самого High Grade задаёт порядок: подтверждённый push в `origin/main`, затем сборка из изолированного опубликованного SHA, preview/apply `global-update` с отпечатком и проверка `global-status`.

## Границы

Навык не выводит право на выпуск из завершённых тестов или OpenSpec без явного вызова. Он не предполагает одинаковую команду активации для разных проектов и не удаляет пользовательские материалы только потому, что они не вошли в коммит.
