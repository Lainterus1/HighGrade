# Уточнить карту проекта по проверке SNAF

## Why

На SNAF `map` включила в карту локальные `artifacts`, `.output`, `.tanstack` и `.pnpm-store`, хотя проект уже перечисляет их в `.highgrade/project/inventory-exclusions.json`. Недоступный `.gstack` из того же списка дал `unknown`. В результате появились ложный второй `package.json` и шаблоны старой локальной поставки как документы проекта; `src/router.tsx` не был отмечен как кандидат на точку входа.

## What Changes

- Карта применяет валидный проектный список исключений до обхода соответствующих путей и показывает фиксированную причину, не копируя свободный текст причин.
- Встроенные исключения охватывают распространённые локальные каталоги сборки и `.highgrade/releases`, сохраняя `.highgrade/project` и скрытые инструкции в области карты.
- `src/router.{ts,tsx,js,jsx}` становится кандидатом на точку входа по наличию файла; фактическая команда запуска не выводится.

## Scope

Изменяются только исходный CLI, его контрактные тесты и справочник кандидата v0-2-2. Проект SNAF служит read-only проверочной площадкой. Пользовательская установка, публикация и содержимое SNAF не меняются.
