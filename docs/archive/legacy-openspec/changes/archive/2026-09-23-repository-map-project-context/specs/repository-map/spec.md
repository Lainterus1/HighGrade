# Spec Delta

## ADDED Requirements

### Requirement: Проектные исключения карты
Карта SHALL при наличии `.highgrade/project/inventory-exclusions.json` применять его валидные относительные пути до обхода соответствующих файлов и каталогов. Она SHALL ограничивать чтение списка своим документированным пределом, использовать ту же структурную проверку и сопоставление путей, что `inventory`, и показывать лишь фиксированную причину исключения без свободного текста из файла. На Windows сопоставление ASCII-букв в путях SHALL выполняться без учёта регистра. Применение списка SHALL не означать одобрение аудита или проверку его receipt. При некорректном списке карта SHALL возвращать `unknown`, не применяя непроверенные записи.

#### Scenario: Список SNAF
- **WHEN** проект объявляет локальные `artifacts` и `.gstack` исключениями
- **THEN** карта показывает их как проектные исключения и не читает дочерние файлы, даже если каталог недоступен

#### Scenario: Небезопасная или некорректная запись
- **WHEN** список имеет неверную схему, путь с выходом из корня или ошибку разбора
- **THEN** карта отмечает неполноту как `unknown` и не скрывает область по непроверенной записи

#### Scenario: Проект без списка
- **WHEN** файл списка отсутствует
- **THEN** карта продолжает обход с встроенными исключениями без зависимости от High Grade-адаптации проекта

#### Scenario: Регистр имени каталога на Windows
- **WHEN** список исключает `artifacts`, а каталог в рабочем дереве Windows называется `Artifacts`
- **THEN** карта и `inventory` пропускают этот каталог по одному правилу сопоставления

### Requirement: Служебные копии и кэши
Карта SHALL исключать `.highgrade/releases`, `.pnpm-store`, `.output` и `.tanstack` как служебные копии или распространённый генерируемый вывод, сохраняя `.highgrade/project` и скрытые инструкции в области обхода.

#### Scenario: Локальная поставка
- **WHEN** в проекте есть `.highgrade/releases/vX/templates/README.md` и `.highgrade/project/documents.json`
- **THEN** карта не выводит шаблон поставки как проектный документ и продолжает учитывать файлы `.highgrade/project`

### Requirement: Кандидат маршрутизатора
Карта SHALL показывать существующий `src/router.{ts,tsx,js,jsx}` как кандидат `entry_points` по относительному пути, не читая исходник и не выводя предположительную команду запуска.

#### Scenario: Файловый маршрутизатор SNAF
- **WHEN** в проекте есть `src/router.tsx`
- **THEN** `entry_points` содержит этот путь и тип `router-file`
