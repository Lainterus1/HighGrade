# Proposal

## Why

Doctor проверяет только заголовок схемы инструкции, но результат compatible может быть прочитан как смысловая совместимость. Обновление обещает лёгкую проверку при входе, не определяя её состав.

## What Changes

- Явно указать машинную границу: поддерживаемый заголовок schema 1, смысловая совместимость не проверена.
- Определить проверку при входе: схема, применимые требования поставки, местные команды, исключения и полномочия.
- Сохранить местные инструкции при обновлении; неизвестная схема и новые конфликты блокируют только зависимые действия.

## Impact

Дополнительные поля измерения doctor без удаления прежнего compatible, процедуры/справочник и шаблон. Новый формат конфигурации и централизованный реестр проектов не нужны.
