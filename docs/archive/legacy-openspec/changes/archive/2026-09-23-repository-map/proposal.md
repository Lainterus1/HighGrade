# Proposal

## Why

`inventory` создаёт полный список файлов и хешей для технического снимка, но не помогает быстро найти входные документы, устройство проекта и его проверки. Общим навыкам High Grade нужна короткая карта выбранного репозитория, чтобы начинать обследование и выбирать контекст задачи без повторного ручного обхода.

## What Changes

- Добавить в общий Rust CLI команду `highgrade map --root <проект>` с ограниченным, воспроизводимым выводом о структуре, вероятном стеке, документах, точках входа, тестах и CI.
- Учитывать отслеживаемые и новые файлы рабочего дерева, включая скрытые инструкции; показывать исключённые и непроверенные области. Читать содержимое только заранее разрешённых типов файлов и не выводить закрытые значения.
- Описать применение карты в общих процедурах init, task, spec, work и clear как вспомогательного средства. Карта не подтверждает полноту или смысловую правильность аудита.
- Сохранить `inventory`, `doctor`, `inspect` и `trace` с прежними назначениями. Поиск контекста задачи и подсказки проверок по изменениям в это изменение не входят.

## Capabilities

### New Capabilities

- `repository-map`: безопасная быстрая карта одного проекта с явными источниками, исключениями и границами вывода для общих навыков High Grade.

### Modified Capabilities

Нет.

## Impact

CLI `src/` и его контрактные тесты; общие процедуры и справочник в `kit/`; действующая архитектура, команды и описание общего маршрута в `docs/`. Новых обязательных внешних инструментов и автоматического обновления установленной пользовательской поставки нет. Целевые проекты не изменяются.
