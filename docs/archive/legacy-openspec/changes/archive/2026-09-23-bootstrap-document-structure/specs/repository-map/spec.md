# Spec Delta

## REMOVED Requirements

### Requirement: Быстрая команда карты

**Reason**: Публичная карта не показывает соответствие обязательной структуре и дублирует обычный поиск агента.

**Migration**: Использовать `inspect --bootstrap --root <проект>` для проверки структуры до реестра; для произвольной ориентации применять целевой поиск и полный аудит `init`.

### Requirement: Область рабочего дерева

**Reason**: Обход рабочего дерева нужен только как часть предварительной проверки структуры, а не как отдельная карта.

**Migration**: Ограничения области и непросмотренных путей определены способностью `project-bootstrap`.

### Requirement: Ограниченное извлечение сведений

**Reason**: Общие эвристики стека, входа, тестов и CI не нужны для сравнения документов с канонической структурой.

**Migration**: `inspect --bootstrap` извлекает только фиксированные структурные признаки документов и связей; остальное агент изучает по задаче.

### Requirement: Корректная граница применения

**Reason**: Процедуры переходят от карты для общей ориентации к предварительной проверке структуры в `init`.

**Migration**: Границы применения закреплены в `project-bootstrap`; `inventory`, `doctor`, обычный `inspect`, `trace` и полный аудит сохраняют собственные задачи.

### Requirement: Проектные исключения карты

**Reason**: Отдельной карты больше нет.

**Migration**: Предварительная проверка применяет валидные исключения по безопасным правилам `project-bootstrap`, без вывода свободного текста причин.

### Requirement: Служебные копии и кэши

**Reason**: Исключение служебных копий требуется для предварительной проверки, а не для публичной карты.

**Migration**: `inspect --bootstrap` сохраняет защиту от служебных копий и генерируемых каталогов в рамках своего обхода.

### Requirement: Кандидат маршрутизатора

**Reason**: Кандидат точки входа не помогает установить обязательные роли документов.

**Migration**: При аудите точку входа ищет агент по файлам и конфигурации конкретного проекта.
