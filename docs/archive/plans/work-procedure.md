# Упорядочение Work без потери проверочных правил

Статус: завершён и перенесён в архив. Технический план одной зависимой задачи; требования к поведению закреплены в HG-0018-R1, HG-0021-R1/R3/R4, HG-0043-R1/R2 и HG-0010-R5. Новая спека не потребовалась: контракт не изменён. Проверки и смысловая сверка — в [таблице случаев](../../evidence/work-procedure/semantic-review.md), независимый итог — в [ревью](../../reviews/work-procedure.md).

## Результат и границы

`highgrade-work` остаётся управляющим маршрутом: выбирает проверку, определяет полноту сценарного доказательства, запускает ревью и закрывает задачу. Условные справочники описывают метод ревью и формат операций. Нового публичного навыка, обязательного пилота, CLI-функции или второго источника требований нет. Посторонние изменения не затрагиваются.

## Карта сохранности

| Действующий блок Work | Владелец после правки | Сохранить в Work |
|---|---|---|
| Вход, Fixer, полномочия | Work; Task/Planner по ссылке | основной источник, границы, итоговый критерий |
| Отчёт и актуальность evidence | Work | фактический запуск перед записью; неизменяемый отчёт; повтор затронутого |
| Независимое ревью | Work запускает; внутренний справочник задаёт метод | порог, момент, передача, GO/NO_GO, повтор и незакрытый барьер |
| Матрица и сценарии | Work; Verification содержит формат операций | реальная логика, риск, утверждения теста, вид доказательства, проектные барьеры |
| Входы сценария | Work | влияющие зависимости, общий отчёт отдельно, осторожное сужение и дрейф |
| Продолжение | Work; Planner хранит цепочку | сверка diff и входов, первый незавершённый шаг |
| JSON-спека | Work управляет; Specifications/Verification задают CLI | условность ветки, порядок, интеграция, пробелы, путь без спеки |
| Передача человеку | Work; Specifications задаёт запись решения | точная версия, действия проверки, явное решение и границы полномочий |
| Передача файлов | Work включает условно; Diagnostics проверяет состав | только порученная передача, невосстановимые отчёты и входы |

## Последовательность

1. Сверить карту с действующими справочниками и входящими ссылками.
2. Сформулировать универсальную инструкцию сценария в Work; добавить условный метод независимого ревью; сократить повтор технического синтаксиса.
3. При необходимости уточнить существующие справочники; обновить генерацию навыка, манифест и ссылки.
4. Проверить таблицу случаев: редактура; скрипт вне trace; браузерный тест; общий прогон и разные входы; дрейф; обязательное ревью; работа со спекой и без неё; передача результата. Провести независимое ревью.
5. Сверить завершённость, архивировать план и оставить в местном состоянии `Next: none`.

## Готовность

Нет «голых» ссылок вместо обязательного действия. Ни одно исходное правило не теряет владельца. Сгенерированный навык и манифест соответствуют исходнику; ссылки/якоря и применимые проектные проверки проходят. Нормативная сверка и независимый GO охватывают сценарии и сохранность правил. Наблюдение поведения модели требуется только для заявления о фактическом исполнении новой процедуры, а не для проверки редакции текста.
