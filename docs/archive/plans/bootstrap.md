# Начальное наполнение MyCodex

Статус: VERIFIED — начальная документация и перенос исходников проверены; runtime плагинов и полный workflow не активированы. Разрешённая область: документация самого MyCodex, перенос существующих пакетов для сопровождения, проверка структуры и точности переноса. Установки, переключение marketplace, публикация, удаление старых копий и реализация универсального workflow не входят.

1. Проверить исходники и установленные копии — выполнено: исходные файлы обоих пакетов совпадают с соответствующими файлами кеша.
2. Подготовить пять документов, навигацию, карту документации и проверку структуры.
3. Скопировать исходные пакеты и документы проектирования в MyCodex, сохранив существующий ранний черновик.
4. Проверить manifests, хеши переноса, структуру и синтаксис. Полные runtime-тесты отдельно.

Next: none для bootstrap. Следующая отдельная задача — прототип P1 переносимого workflow; функциональные проверки плагинов на новом месте требуют подготовки их окружений.

Единственная текущая задача bootstrap описана здесь. Технический план P1–P6 остаётся будущей реализацией workflow; он не выполняется автоматически этим переносом.

Проверено 2026-09-22: оба manifest прошли штатный валидатор; 26 Python-файлов разобраны без синтаксических ошибок; Node-скрипт прошёл синтаксическую проверку; в целевом каталоге проверены структура и SHA256 всех 54 импортированных файлов. Тесты поведения плагинов не запускались. Git и marketplace не изменялись.
