# Проверка разделения approve и push

Дата: 2026-09-23–24. Статус: локальный кандидат v0-2-7 прошёл проверки и повторное независимое ревью; OpenSpec [архивирован](../../../openspec/changes/archive/2026-09-23-approve-push-workflow/tasks.md). Это запись доказательства исходников, не решение о публикации или активации. SNAF и другие целевые проекты не менялись.

## Проверено локально

- Строгая валидация изменения перед архивированием и всех пяти действующих спецификаций после него прошла.
- `cargo fmt --all -- --check`, `cargo test --locked --quiet` (71 тест), `cargo build --release --locked`, `node scripts/check-repository.mjs` и `git diff --check` прошли.
- Контрактные тесты включают установку v0-2-7, переход с v0-2-6, откат к ней и прежним выпускам, защиту от изменённого кандидата и конфликтующих маршрутизаторов. Профили тестов изолированы.
- `global-status` подтвердил фактическую пользовательскую v0-2-6. Preview `global-update` с собранным кандидатом показал переход к v0-2-7 и потребовал смысловой проверки. Применение не запускалось.
- До архивации `inspect` показывал временное превышение из-за одновременной загрузки действующей спеки и активных дельт. После объединения требований и сокращения повторов в действующих документах маршрут занимает 93 320 байт при согласованном бюджете 94 000; бюджет не повышался. Пути и внутренние ссылки реестра проверены. Внешняя ссылка README остаётся непроверенной самим `inspect`.

## Независимое ревью

Независимое ревью изменения поведения обязательно по [правилам качества](../../workflow/QUALITY.md). Первый запуск `codex review --uncommitted` отклонила автоматическая проверка разрешений из-за передачи diff внешнему сервису. После явного разрешения автора ревью выявило P1: первый выпуск v0-2-7 не мог использовать ещё не установленный `highgrade-approve`, а проектный маршрут замыкался на себе. Добавлен разовый переход через локальную часть процедуры действующей v0-2-6 с активацией из коммита. Повторное ревью после исправления и финальное ревью после архивации не выявили замечаний, требующих исправления.

## Незавершённое

CI в GitHub не выполнялся: кандидат не отправлялся. Локальная активация и пользовательская приёмка v0-2-7 не проводились.
