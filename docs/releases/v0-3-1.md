# Поставка v0-3-1

HG-0045–HG-0047: последовательная инициализация с сохраняемым обследованием.

- JSON со схемой и читаемым представлением работает до specs и реестра документов.
- Семь ключевых решений, карта проекта, основания, зависимые пробелы и следующий шаг.
- Структурный inventory сохраняет конфигурацию и различает исключения/неполноту; legacy-команды совместимы.
- Выбранные источники и состав областей определяют актуальность. CAS, атомарная запись, ревью go/no_go, завершённая история и reopen поддерживают продолжение.
- Init разделяет обследование, разрешённую адаптацию и проверку; сохраняет существующих владельцев документов. Схема, шаблон и справочник входят в установку.

Проверки: **168 Rust**, **89/89 автоматических сценариев**, scale 100/200, reuse, формат, генерация, структура, inspect и независимое [REVIEW_GO](../reviews/init-redesign.md). [Нормативная сверка](../evidence/init-redesign/normative.md) проверяет инструкции без обязательных агентных пилотов. Остальные 81 сценарий не объявлены автоматически пройденными.

CLI не подтверждает истинность обследования и человеческую приёмку. Частичность, неизвестность и отрицательное ревью остаются явными. Активация выполняется из точного коммита через один candidate_sha256 и проверяется global-status. Публикация не назначена.
