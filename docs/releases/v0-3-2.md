# Поставка v0-3-2

HG-0048–HG-0050: переносимость доказательств, готовность действий обследования и устойчивые интерфейсы CLI.

- Doctor проверяет обязательные файлы передачи по Git index либо явному bundle; читает исходные blob без фильтров и обхода через флаги индекса.
- Survey разделяет готовность плана, адаптации и завершения; редактирование сохраняет фактический этап, значимый diff инвалидирует ревью. Чтение v1 сохранено.
- Report даёт именованный result при сохранении measurements; check допускает отдельный launch_selector. Пропуск/дубль/ошибка теста не являются успехом.
- Init проверяет совместимость создаваемых файлов с инструментами проекта и маршрут хранения доказательств. Инструкции не требуют повторного пилота для нормативной правки.

Проверки версии 0.3.2: 177 Rust-тестов без пропусков, 96 автоматических сценариев; формат, генерация, структура, inspect. Источники: [отчёт](../evidence/pilot-release-v032/verify.json), [нормативная сверка](../evidence/pilot-followup/normative.md), [ревью](../reviews/pilot-followup.md). Inspect сохраняет 9 предупреждений ExternalLinkUnchecked; внешние ссылки не проверены.

Автор принял показанную редакцию HG-0048–HG-0050 и поручил активацию и публикацию. [Решение](../evidence/pilot-followup/human-decision.json) сохраняет её точные отпечатки. Повторные проверки после смены версии записаны отдельно; прежняя приёмка не переносится на изменившиеся отпечатки автоматически.

Активация — из точного SHA коммита через preview/apply и global-status. Публикация — origin/main с проверкой удалённого SHA и CI. Фактическое завершение этих действий сообщается отдельно; документация не служит доказательством их исполнения. Другие проекты и установленные плагины не меняются.
