# Поставка v0-2-22

Цепочка HG-0026–HG-0032: достаточные проверки, полные генерируемые навыки, безопасная замена принадлежащих установке навыков и global-recover, адаптация существующих документов, устойчивые отпечатки повторных проверок, компактный spec-read/edit, общие входы checks и единое явное решение о приёмке/активации показанного результата.

Местные правила сокращены до проектных решений; матрица проверок — в DEVELOPMENT. Дополнительные постоянные роли не вводились. Для текстовых изменений агентные упражнения не выполнялись; нормативное ревью не объявляется доказательством будущего поведения агента.

Новые поля evidence.input_paths и shared_inputs требуют CLI этого выпуска. Старые записи читаются без переписывания; после нового наблюдения со старым отпечатком может понадобиться повторное ревью. Откат CLI не откатывает формат проектных данных.

Локальный выпуск собирается из точного коммита через build-release.py, затем проходит preview/apply с одним candidate_sha256 и global-status. Публикация не поручена. Фактический результат активации определяется установкой, а не наличием этой записи. Доказательства цепочки хранятся в specs/changes/HG-0026–HG-0032; исходный финальный отчёт — в HG-0032/evidence.
