# Выпуск v0-4-1

Назначены коммит, локальная активация и push показанных исправлений и выбранной очистки. Предыдущая установка — v0-4-0; её global-status прошёл. Версия 0.4.1 выбрана по правилу patch increment. Формат каталога и launcher protocol не меняются. Человеческая приёмка не назначена.

## Состав

Пакет включает ранее проверенную цепочку HG-0063-T10 → HG-0076, результаты двух проходов Clear и [последние исправления с очисткой](../evidence/diff-cleanup-2026-10-14/closure.md). Сводка пользовательских изменений хранится только в [release-notes.json](../../kit/references/release-notes.json). Здесь указаны происхождение, проверки и пределы выпуска.

Выбраны связанные исходники, тесты, документация, native history/results и необходимые исходные отчёты. Presentation исключён; содержимое не читалось и не менялось. Чужая правка .gitignore остаётся вне коммита. Двадцать два избыточных CLI ответа и две прежние выборки сохранены для восстановления в локальном архиве, нужные исходные отчёты остаются в CAS. История и полезные тесты сохранены.

## Проверки и пределы

Для подготовки 0.4.1 выполнены полный Rust Nextest, trace, 14 реальных Node guard cases, scale/reuse, UI build и адресные workflow checks. Проверки первого прохода 0.4.1 до окончательного сокращения release metadata сохранены отдельно. Финальный комплект указан в [индексе выпуска](../evidence/releases/v0-4-1-pre-submit.json). Остальные неизменённые Python/helper/browser/plugin проверки переиспользованы с прежними пределами из связанных отчётов. Windows CI проверит опубликованный SHA отдельно.

Spec-check не объявляет весь HG-0063, HG-0076 или прежний Clear готовым. Старые actor/manual записи HG-0076 устарели по hash причинных инструкций; прочие прежние пробелы сохранены. spec-delivery для этих старых записей отмечает расхождение старых inputs с новым пакетом, включая игнорируемый development UI manifest. Обязательные исходные runner reports выбраны. Эти диагностические отказы не переименованы в PASS и не заменены новыми actor наблюдениями. Полная доступность всех старых причинных bytes не заявлена; адресные пределы перечислены в индексе.

GO относится к показанным и проверенным исправлениям и составу выпуска. Оно не подтверждает все методы старых спецификаций, Windows, устойчивое выполнение навыка моделью или человеческую приёмку. Tool/environment identity и ancestor/home Cargo config не запечатаны полностью. Общая проверка очистки сохраняет прежний hg58; это не общий PASS обслуживания.

## Доставка

Исходный коммит и его активация не были записаны на момент подготовки этого документа. После коммита используется только штатный build-release.py с точным SHA. Затем выполняются preview, смысловое сравнение, apply с тем же candidate_sha256 и global-status. Подтверждение добавляется отдельной записью без переписывания прежних результатов. Push назначен в существующую origin/main, без force, tag и hosted deployment; workflow запускает CI Linux/Windows.
