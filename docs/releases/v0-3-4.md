# v0-3-4 — локальный интерфейс спецификаций

Пакет HG-0052–HG-0058: локальный UI без Node у пользователя, исходный текст спецификаций, редактирование через CAS, разделённые согласование и приёмка, компактная карточка, отмена устаревших чтений, локальные Manrope/иконки/логотип, каталог Storybook для развития.

Пользователь поручил активировать поставку и отправить изменения после передачи выполненной HG-0058. Приёмка показанной редакции сохранена CLI; коммит/активация/публикация — отдельные действия. Предыдущий выпуск v0-3-3, базаGit dca18d4e4201d0ab5308587525b0a73547c72ce8.

До коммита:189 Rust,15 проверок сборочного цикла,25 browser; после свежего Storybook повтор 8 visual/keyboard;113/113 автоматических сценариев trace. Независимое ревью состава GO. Отчёты и снимки входов — [проверки выпуска](../evidence/specification-ui/release-v034/verification.md). Проверки старых промежуточных спек не выдаются за текущие: часть их evidence устарела после уточнений HG-0058; технический результат актуального компактного интерфейса закреплён HG-0058.

Кандидат создаётся штатным build-release.py из точного коммита; установленный E2E, preview/apply/global-status и удалённый CI проверяются после подготовки этого SHA. Эта запись сама по себе не утверждает успех ещё не выполненных действий. Результаты сохраняются в candidate.json и отчёте передачи текущего сеанса.
