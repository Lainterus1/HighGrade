# Поставка v0-2-20

Выпуск реализует [HG-0024](../../specs/changes/HG-0024/spec.json): отчёт различает случаи в исходном отчёте, выполненные, пропущенные, неизвестные и отсутствующие Rust-тесты, связанные тесты и сценарии вне автоматической области. Отсутствующая автоматическая связь не подменяет ручное доказательство. Тестовые временные каталоги очищаются при завершении теста, включая панику; фактические результаты и ограничения приведены в [аудите](../evidence/spec-verification/HG-0024-test-audit.md).

Манифест и CLI имеют версию `0.2.20`. Для готовности требуются `spec-check` HG-0024, Nextest, trace, проверки структуры и независимое ревью; точные итоги проверки должны относиться к коммиту кандидата. Локальная активация выполняется только из этого коммита через preview → apply и подтверждается `global-status`. Публикация в Git и человеческая приёмка независимы от активации.
