# Поставка v0-2-15

Состав: действующие требования Проекта приведены к нативному каталогу `specs/`; прежние OpenSpec-материалы сохранены в архиве. Обновлены маршруты Поставки, пользовательский README и проверки CI. Изменённая Поставка получила новый неизменяемый release ID; временные синтетические проекты прогонов удалены.

Автор 2026-09-25 явно принял все 15 действующих спек и остановил дополнительные агентные пилоты. [Точная запись решения](../evidence/spec-verification/2026-09-25-human-decision.json) сохраняет редакции на момент решения. Это решение не превращает непроверенные сценарии в `passed`: для HG-0010 и HG-0011 исходно оставались пробелы, а смена версии Поставки сделала часть сохранённых доказательств устаревшими по отпечаткам входов. Машинный `spec-decide` не записывает `accepted` при `spec-check: failed`; состояние CLI следует читать отдельно.

Проверено на рабочем дереве перед коммитом: `cargo test --locked`; Nextest 116/116; связь автоматических сценариев 38/38 при 51 неподтверждённом ручном; `cargo fmt --all -- --check`; `check-repository --verify-import` (54 файла); `check-spec-archive` (86 OpenSpec и 124 нативных файла); `check-scenario-scale`; тесты `scripts/tests` 7/7. `inspect` дал только предупреждения о непроверенных внешних ссылках. Это проверки исходников и структуры, не пользовательская приёмка каждого сценария Поставки.
