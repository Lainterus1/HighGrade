# Поставка v0-2-23

HG-0033–HG-0037: компактная история результатов, атомарный spec-evidence-batch, импорт штатного JUnit со снимком входов, справка команд, раздельные поля технической проверки и решения, диагностика выбранного действия, ранняя фильтрация списка и локальный CAS редактирования.

Проверки: 144/144 теста Nextest; 69/69 автоматических сценариев каталога, включая 12 новых. 72 прежних сценария вне автоматической трассировки не объявляются проверенными этим прогоном. Исходные результаты — [tools-cli](../evidence/tools-cli/verify.json); сохранность 29 исторических файлов подтверждена сравнением с прежними данными после разворачивания истории.

Результаты каталога после явной миграции занимают 2 360 443 байта вместо 8 721 596 до добавления новых доказательств. Каталог формата 4 требует совместимую CLI; автоматического отката формата при смене CLI нет. Импорт пока поддерживает JUnit, файловое чтение каталога остаётся общим. Legacy-команды сохранены для совместимости. Прежние статусы и exit code диагностики сохранены, новые поля объясняют их отдельно.

Итоговый выпуск собирается из точного коммита через build-release.py и активируется preview/apply одного кандидата. Фактическая активация определяется global-status. Публикация и человеческая приёмка готовых спек не выполняются этим маршрутом автоматически.
