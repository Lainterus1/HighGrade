# Выпуск v0-2-7

Состояние: исходный состав подготовлен к локальному принятию, активации и публикации. Эта запись обновляется по факту каждого этапа; SHA и CI нельзя считать подтверждёнными до их проверки.

## Состав и проверки

Разделены `highgrade-approve` для локального принятия задачи и `highgrade-push` для отправки диапазона коммитов. Сохранён `highgrade-update`; миграция с v0-2-6 и откат проверены на изолированных профилях. OpenSpec-изменение [архивировано](../../openspec/changes/archive/2026-09-23-approve-push-workflow/tasks.md). Независимое ревью и локальные проверки зафиксированы в [отчёте](../reviews/approve-push-workflow-review.md). CI проверяет исходник после push; он не активирует пользовательскую установку и не развёртывает целевые проекты.

## Фактические этапы

- Исходный коммит: ожидает создания.
- Локальная активация: ожидает `global-update` из изолированной копии исходного коммита.
- Удалённая публикация: ожидает push в `origin/main`.
- CI: ожидает отправки коммита.
- Пилоты SNAF и других проектов: не проводились.

Откат локальной установки после активации: `global-update --rollback v0-2-6`, затем `global-status`. Откат не отменяет опубликованный Git-коммит.
