# v0-3-9 — проверка поведения до реализации

Выпуск включает HG-0066: узкая проверка согласованного поведения до изменения реализации, короткий цикл, переиспользование пригодных тестов и соразмерные исключения. Существующее итоговое ревью сверяет силу утверждений и причины изменения ожиданий. Проектный пример проверяет отказ настоящей CLI и сохранность каталога. Rust-поведение, формат каталога и API не изменены; версия Cargo и манифеста синхронизирована для нового неизменяемого выпуска.

Автор 2026-10-01 поручил коммит, локальную активацию и прямую публикацию в main. Это разрешение не означает человеческую приёмку спецификации. Основа — `d195324e67a42ca0ed117b131aad15809815cf03`; кандидат собирается штатным `build-release.py` только после коммита из его точного SHA.

Нормативные доказательства и независимое ревью обновляются для передаваемого состава; подробности — в [проверке публикации](../evidence/test-before-implementation/publication-verification.md). Применение требует preview, смысловую сверку и apply одного `candidate_sha256`, затем успешный global-status. Финальные Windows/Ubuntu CI проверяются для опубликованного SHA. GitHub tag/release и человеческая приёмка не включены в поручение.
