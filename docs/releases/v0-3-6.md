# v0-3-6 — перенос проекта и совместимая локальная поставка

Выпуск объединяет удалённую `main` v0.3.5 (`66f61f709449c7116f28c79385206008bf783710`) с локальным коммитом поддержки Unix (`fda4117312ca4c5af4388c960081dac94c10ea8f`). Оба коммита остаются в истории `main`. Спецификация интерфейса HG-0052 и исходная запись v0.3.4 из удалённой ветки сохранены; локальное требование перенесено в HG-0060, а [прежняя локальная запись](../archive/releases/v0-3-4-linux-local.md) обозначена исторической.

Установка сохраняет право исполнения CLI в Unix и проверяет его; UI и его тесты используют платформенное имя файла и браузер Playwright либо явно заданный `HIGHGRADE_CHROME`. Общие скрипты проверки и CI работают с Windows и Ubuntu. Публичные команды CLI и локальный контракт UI сохранены.

Фактические проверки объединённого кода, ревью и результаты локальной активации приведены в [отчёте выпуска](../evidence/release-v036/verification.md). Локальный результат на Omarchy не подтверждает Windows CI: он станет проверяемым после отдельной публикации коммита. Эта запись не обозначает GitHub push или пользовательскую приёмку.
