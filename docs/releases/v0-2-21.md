# Поставка v0-2-21

Локальный выпуск из текущей редакции Проекта после HG-0025. Манифест и CLI имеют версию `0.2.21`. Изменения HG-0025 относятся к проектным скриптам, каталогу, документации и CI; они не входят в переносимую Поставку. Поведение установленной CLI и содержимое `kit/` по сравнению с v0-2-20 не меняются, кроме идентификатора выпуска.

Кандидат собирается один раз из точного коммита с этой версией через `python scripts/build-release.py <SHA>`. Местная активация требует preview, apply с тем же `candidate_sha256` и успешного `global-status`. Коммит, активация, публикация в Git и пользовательская приёмка остаются отдельными состояниями.
