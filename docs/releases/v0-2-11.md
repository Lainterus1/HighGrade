# Выпуск v0-2-11

CLI 0.2.11. Исправление clarify-update-safety: происхождение кандидата, повтор установленного состава, конфликт release ID и фактическая диагностика после сбоя. CLI-поведение и стабильные маршрутизаторы не изменены. [Доказательства и ограничения](../../openspec/changes/archive/2026-09-24-clarify-update-safety/evidence.md).

Автор разрешил фиксацию и отправку; применяется местный маршрут approve с активацией из изолированного SHA, затем push в origin/main. SNAF не входит в область.

Статус: подготовка выпуска. Next: проверки версии → коммит → сборка из SHA → preview/apply → global-status → push и проверка удалённого SHA/CI. Результаты дополняются после фактического исполнения.

Независимое ревью исправления: REVIEW_GO после устранения P2. Упражнение подтверждает сбой stage, но не отказ самого отката. Превышение бюджета контекста сохраняется как рассмотренное предупреждение; потолок не повышается.
