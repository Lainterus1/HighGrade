# v0-3-8 — поставка объединённых изменений

Версия 0.3.8 назначена автором 2026-10-01. Основа — main `0539663fd785083b100a1cb00408cae25f41b2b1` после PR #9. Изменение выпуска синхронизирует Cargo, lockfile, манифест Поставки и ожидания версии установочных фикстур; поведение CLI, UI и процедур не меняется. Исторический `bundle/` не обновляется.

## Проверка и границы

- [Проверки исходной основы на Windows и Ubuntu](https://github.com/Lainterus1/HighGrade/actions/runs/36867286934) используются только для неизменённого поведения. Новый номер версии не переносит эти результаты на новый SHA.
- Для кандидата требуются согласованность версии и хешей kit, проверка структуры, установочные фикстуры, сборка `build-release.py` из точного SHA и smoke установки в изолированном временном профиле. Это не активация пользовательского профиля.
- Windows/Ubuntu CI нового SHA остаётся отдельным барьером после разрешённой прямой публикации в main; результаты видны в [Verify source](https://github.com/Lainterus1/HighGrade/actions/workflows/verify.yml).
- Известный NO_GO HG-0063 и отсутствующие наблюдения Goal/native не закрываются выпуском. Каталог спецификаций, evidence и человеческая приёмка не изменяются.
- Установка на компьютере автора, GitHub tag/release и деплой не выполняются этим изменением.
