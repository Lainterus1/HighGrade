# Проверка highgrade-deploy v0-2-6

Статус: кандидат исходников проверен; пользовательская установка не переключена. Изменение OpenSpec: [deploy-publication-consent](../../openspec/changes/archive/2026-09-23-deploy-publication-consent/proposal.md). Действующий контракт: [release-workflow](../../openspec/specs/release-workflow/spec.md).

## Проверенный результат

- `highgrade-deploy` по умолчанию завершает принятую задачу локальным коммитом. Push, PR, тег и активация требуют отдельного явного поручения; проектная инструкция или связанный runbook задаёт цель и команды. Для High Grade эти детали находятся в [проектной инструкции](../../.highgrade/project/INSTRUCTIONS.md).
- Переход с установленного `deploy` v0-2-5 создаёт новый маршрутизатор до переключения активного указателя и удаляет старый после проверки. Откат восстанавливает маршрутизатор целевого релиза из его проверенной копии. Неактивный остаток показывается предупреждением; новый навык проверяет владение в активном журнале, а новая процедура останавливает вызов через старое имя.
- Независимое ревью обнаружило разрыв при замене прежнего маршрутизатора на месте. Переименование устранило этот риск; повторное ревью дало `REVIEW_GO` без подтверждённых дефектов.

## Доказательства

- `cargo fmt --all -- --check`; `cargo test --locked` — 69 тестов; `cargo build --release --locked`.
- `node scripts/check-repository.mjs`; проверка навыка `quick_validate.py kit/skills/highgrade-deploy`; хеши всех файлов `kit/` по манифесту в `global_contracts`.
- `openspec validate 2026-09-23-deploy-publication-consent --strict --no-interactive`.
- После архивации `highgrade inspect` измерил активный маршрут в 93 130 байт против прежнего бюджета 90 000. Пересмотрены состав и дубли: дельта и задачи вынесены в историю, итоговая спецификация содержит отдельные правила полномочий и миграции. Рабочий бюджет поднят до 94 000 в пределах согласованного потолка 96 000; проверка повторяется после двух реальных задач `highgrade-deploy`.
- На реальном профиле выполнен только preview `global-update`: кандидат `v0-2-6` распознан с действующей `v0-2-5`; статус `unknown` означает требуемую смысловую проверку перед применением, а не ошибку совместимости.
- Временные профили проверили миграцию с шестью навыками и с `deploy` v0-2-5, откат, конфликт чужого маршрутизатора, ошибку переключения указателя и прерванное состояние с лишним файлом.

## Граница

Коммит, push, переключение пользовательской установки и приёмка целевых проектов в этой задаче не выполнялись. Если Windows не позволит удалить прежний маршрутизатор после переключения, он останется видимым до проверки и очистки; активный журнал остаётся валидным, `global-status` выдаёт предупреждение, новая процедура останавливает вызов через старое имя.
