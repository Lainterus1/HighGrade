# Проверка кандидата repository-map

Дата: 2026-09-23. Область: исходный кандидат High Grade v0-2-2; пользовательская установка остаётся v0-2-1. Изменение выполнялось по `openspec/changes/repository-map`.

## Результат

- `cargo fmt --all -- --check`, `cargo test --locked` (57 тестов), `cargo build --release --locked` прошли. Контрактные тесты карты проверили новые и скрытые файлы, закрытые значения, неизвестный стек, ошибочный `package.json`, пределы входа и печатаемого JSON, длинные пути, неверный корень и Windows junction за пределы корня.
- `node scripts/check-repository.mjs` прошёл. `openspec validate --all --strict --no-interactive` проверил изменение и действующую спецификацию (2/2). Все 22 SHA256 в `kit/manifest.json` совпали с исходниками пакета.
- Релизный CLI установил v0-2-2 в отдельный временный профиль; `global-status` подтвердил поставку, установленный `map` вернул `passed` на этом репозитории (302 видимых файла). Временный профиль удалён после проверки пути.
- До архивирования `inspect` измерил маршрут 79 475/80 000 байт. После архивирования активных задач в маршруте осталось 77 234 байта; бюджет снижен до 78 000. Статус `warning` вызван только непроверяемой локально внешней ссылкой в README; превышения бюджета нет.

## Независимое ревью

Проверяющий нашёл пропуск локального навыка с именем `build`, длинный путь в `top_level`, невалидный `package.json` без статуса `unknown` и несовпавший хеш справочника CLI. Исправления внесены и покрыты тестами либо сверкой всех хешей. Дополнительно проверены предел печатаемого JSON и Windows junction в автоматическом тесте. Итог независимого ревью — `REVIEW_GO` для стабильного рабочего дерева; подтверждённых замечаний не осталось.

## Граница результата

Карта служит для выбора дальнейшего чтения и не доказывает полный аудит, правильность содержимого или выполнение тестов целевого проекта. Обход рассчитан на стабильное рабочее дерево: конкурентная замена каталогов или файлов другим процессом между проверкой пути и чтением может дать устаревший результат или выход чтения за заданный корень. Враждебная конкурентная модификация не проверялась и потребовала бы обхода по дескрипторам. Пользовательская установка, публикация и пилоты не входят в это изменение.
