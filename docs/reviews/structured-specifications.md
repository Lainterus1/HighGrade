## Пределы и сопровождение

CLI проверяет структуру, объявленные входы и отпечатки; смысл сценариев, полноту состава входов и подлинность отчёта устанавливают агент и ревью. JSON Schema генерируется из закреплённых Rust-типов; семантические ограничения проверяет CLI. Один store ограничен 8 МиБ, сбой питания/диска не покрывается гарантией атомарной видимой замены.

Историческое описание стабильного router highgrade-spec содержит OpenSpec; его байты сохранены ради совместимости существующего Update. Исполняемая процедура и справочник задают нативный маршрут. Изменение метаданных router потребует отдельной безопасной миграции; это не зависимость нового workflow от OpenSpec.

Бюджет полного контекста пересмотрен: убрано дублирование из входных документов, переходные задачи и план исключены из обычного маршрута после архива. Действующие контракты сохранены, общий потолок не повышен. Полное чтение всех областей остаётся выше прежнего бюджета; агент читает область задачи по реестру. Предупреждение не означает успешную проверку бюджета.
