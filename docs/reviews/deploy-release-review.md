# Проверка кандидата deploy и состав первого выпуска

Статус: исходный кандидат v0-2-5 проверен и готов к публикации; факт push и локальной активации устанавливается отдельно по Git SHA и `global-status`.

## Принятый состав

- Самоприменение High Grade: OpenSpec, реестр, действующие документы, перенос завершённых планов и доказательства в архив.
- Замена экспериментальной публичной `map` на документный `inspect --bootstrap`, доработка передачи результата в `init` и тесты; ранние подходы и причины замены сохранены в архивных OpenSpec и ревью карты.
- Общий `deploy`, инструкция выпуска в этом проекте, совместимое обновление профиля с шести до семи навыков и откат. `highgrade-update` и технический `global-update` сохранены.

В состав не входят исходники плагинов SVG Vectorizer и Code Health Audit, целевые проекты SNAF/PlantsNotify, пользовательский профиль, кэши и сборочные результаты. Проверено отсутствие ранее подготовленных файлов в Git index. Лицензия `LICENSE` уже отслеживается и не менялась. В новых материалах — собственные процедуры, код и тесты этого репозитория; посторонних заимствованных фрагментов не выявлено. Поиск ключей, паролей, токенов и приватных ключей в затронутом исходном дереве не нашёл совпадений.

## Проверки

- `cargo test --locked`: полный набор Rust тестов прошёл; отдельно восемь контрактных тестов глобальной установки охватили переход с шести навыков, конфликт пути, повторную активацию и сбои указателя/маршрутизатора.
- `cargo build --release --locked`, `cargo fmt --all -- --check`, `node scripts/check-repository.mjs`, проверка навыка `quick_validate.py`: прошли.
- OpenSpec: строгая проверка изменения до архива и всех действующих спецификаций после архива; архивные изменения проверены. `inspect` проверил ссылки и бюджет контекста после перехода на итоговую спеку.
- Независимое ревью обнаружило сбои компенсации при переключении релиза; после исправления и дополнительных Windows тестов дало `REVIEW_GO`. При двойном отказе основной операции и компенсации может потребоваться ручное восстановление; ошибка сообщается явно.

## Граница выпуска

До push это доказательство готовности кандидата, а не публикации. Для первой активации нужна изолированная копия подтверждённого SHA `origin/main`, новый release build, `global-update` preview и apply по его отпечатку, затем `global-status`. Предыдущий v0-2-1 сохраняется для отката. Успех этих шагов не означает приёмку SNAF или другого проекта.

Первый push `9d39f09` выявил пропуск в проверке упаковки: Windows `git archive` с `core.autocrlf=true` выдал для части `kit/` CRLF, тогда как манифест содержал хеши LF; preview остановился до изменения пользовательской установки. Исправление закрепляет `kit/** text eol=lf`, пересчитывает манифест по этим байтам и проверяет LF в контрактном тесте. Публикацию следует считать завершённой только после повторного preview из изолированной копии исправленного SHA.

Повторный preview обнаружил у прежней установки шесть маршрутизаторов с эквивалентным текстом, но CRLF вместо LF. Обновление теперь сохраняет их проверенные исходные байты и отражает их хеши в новом журнале; содержательно отличающийся или чужой маршрутизатор по-прежнему блокирует переход. Отдельный контрактный тест проверяет применение и откат с таким профилем.
