## Исправления

- Трассировка больше не выдаёт PASS при неверном хеше отчёта, противоречивых дубликатах и отсутствии обязательной привязки исходника. Счётчики исходных случаев отделены от уникальных ключей. Сохранены различия между failed, unknown, stale и областью вне автоматической трассировки.
- Проверка полноты пакета UI требует Lora и её лицензию. Отрицательная регрессия удаляет все поставляемые копии, а не один дублирующий файл.
- Тесты проверяют порчу evidence той же длины, конфликт восстановления нескольких файлов, независимость revision и отсутствие повторного POST при StoreBusy.
- Усилены проверки установленного кандидата, схемы и владельца браузерного отчёта, происхождения обоих шрифтов и сохранения посторонних файлов. Фикстура запуска UI читает полный JSON и сохраняет причину сбоя процесса.
- SVG-регрессия обнаруживает удаление ограничения разницы рендера: `+2/255` разрешено, `+3/255` отклоняется. При отказе готовый SVG и отсутствующий выходной каталог сохраняются.
- CHA-тесты учитывают заявленную матрицу runtime. Непроверенный Linux runtime должен дать точный `RUNTIME_UNVERIFIED`, а не ложную сертификацию. Производственная матрица и зависимости не менялись.
- Архивный валидатор признаёт явное последующее снятие ID через `retired_ids`. Необъяснённая потеря и повторное активное использование снятого ID по-прежнему отклоняются.
- Документация уточняет фактические каталоги, доказательства v5, сборку UI, GET/POST, черновики, сохранность и команды. Справка CLI отражает необязательный ID там, где это уже поддерживает реализация.
