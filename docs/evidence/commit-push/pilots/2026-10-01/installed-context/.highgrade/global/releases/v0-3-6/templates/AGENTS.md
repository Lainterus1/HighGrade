# Маршрут проекта High Grade

Для инициализации, проработки задачи, спеки, выполнения, выпуска принятого результата, обзора состояния и обновления общего инструментария используй соответствующие глобальные навыки High Grade. Местные решения читай в [проектной инструкции](.highgrade/project/INSTRUCTIONS.md), затем переходи только к нужным действующим документам по ссылкам. Если инструкции нет, предложи `highgrade-init` прежде применения правил High Grade. После обычной работы не запускай `highgrade-clear` автоматически. Местные навыки дополняют общие; принятое распределение обязанностей сохраняй, новый неразрешённый конфликт покажи до зависимого действия.

Маршрут выбирается по процедуре task активной Поставки: изменение требований — через spec; техническая работа и исправление по неизменному контракту — через work. Для последовательных зависимых задач или спек используй `highgrade-planner` и один Goal на всю цепочку; это принятое проектом поручение на Goal, включая автоматический выбор Planner. При явном запросе только плана ограничь Goal подготовкой плана. Проверки и ревью определяются риском, не наличием spec ID.
