# Исправление Windows-фикстур при публикации HG-0062–HG-0065

2026-10-01: исходный [CI d8b8103](https://github.com/Lainterus1/HighGrade/actions/runs/36851163012) обнаружил две ошибки Python-тестов инвентаризации в Windows. Пересоздание `os.stat_result` из десяти tuple-полей теряло дополнительные Windows-атрибуты: `st_file_attributes=None` вызывал отказ проверки reparse point. Исправлены только тестовые фикстуры: сохраняются все исходные `st_*`, затем исключаются или переопределяются проверяемые поля. Production-инструмент, его guard и утверждения тестов не изменены.

Новый [Python-отчёт](python-tests.log): 52/52 теста, включая все 14 maintenance-проверок. [Входы и среда](checks.json) выбраны до запуска и сверены после него без drift. Локальная ОС — Omarchy 4.0.4 (Arch), Python 3.14.7, Node 26.8.2. Это отдельное наблюдение от Ubuntu 24.04 и Windows 2025 в GitHub Actions.

Свежий локальный Nextest: 211/211 без failures/errors/skips, завершённая attempt/completion и совпавшие входы. Первая попытка в песочнице остановилась на запрете bind 127.0.0.1 для UI-фикстур; повтор с loopback-доступом прошёл. Общие локальные native-отчёты остаются в штатном `target/nextest/highgrade`, их идентификаторы и хеши указаны в checks.json; удалённые отчёты каждого опубликованного SHA сохраняет CI workflow. Логи прежних доказательств не переписаны.

Через CLI обновлены только затронутые evidence HG-0065: HG-0044-S1/HG-0065-S1; прежняя область входов сохранена. Требования и архивные задачи не изменялись. Исправление предназначено для кандидатного коммита и повторного CI в [PR #9](https://github.com/Lainterus1/HighGrade/pull/9); локальный Linux-прогон не объявляется Windows CI. HG-0063 S6/S7/S8 остаются unknown, конфликт Planner/Goal и human=pending сохранены. Приёмка, merge, release и активация не выполнялись.

Валидация каталога/trace, масштаб 100/200, reuse, генерация, структура и fmt прошли. Inspect: 9 предупреждений о внешних ссылках, без failed/unknown.
