D1 — Какой разделитель требуется для импорта CSV в отчётную систему?
Контекст и последствия: формат ещё не установлен; неверный разделитель сделает выгрузку непригодной для импорта.
Рекомендую: A, если у импортёра нет собственного требования к разделителю.
A) Запятая `,` — обычный CSV; импортёр, ожидающий `;`, не прочитает колонки правильно.
B) Точка с запятой `;` — подходит импортёру с таким правилом; импортёр, ожидающий `,`, не прочитает колонки правильно.
Свой вариант: укажите требование импортёра.

D2 — В каком часовом поясе записан `created_at` и какой пояс нужен в CSV?
Контекст и последствия: пример `2026-09-25T10:00:00` не содержит смещения; неверное предположение сдвинет время заказа при импорте.
Рекомендую: A, только если источник подтверждает UTC; иначе B и точное имя исходного пояса.
A) Исходное время уже UTC; CSV содержит ISO 8601 с `Z` — однозначное время без пересчёта.
B) Исходное время в указанном поясе IANA; CSV содержит пересчитанное UTC с `Z` — однозначное время, но нужно точное имя исходного пояса.
C) Исходное время в указанном поясе IANA; CSV содержит местное время с числовым смещением — сохраняет местные часы, но импортёр должен понимать смещение; нужно точное имя исходного пояса.
Свой вариант: укажите исходный пояс и формат времени, ожидаемый импортёром.

Можно ответить на оба вопроса одним сообщением: `D1 A/B; D2 A/B/C`. Для D2 B/C укажите имя исходного пояса.
