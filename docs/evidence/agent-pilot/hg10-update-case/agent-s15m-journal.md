# Дополнительная проверка HG-0010-S15: одинаковый ID, разный состав

## Вход и подготовка

Проверка ограничена `D:\my_projects\MyCodex\target\update-pilot`. В установленном изолированном `profile` активен v0-2-14: [сырой статус до пробы](agent-s15m-status-before.json) с кодом 0 и [команда с временем UTC](agent-s15m-status-before-command.json). До эксперимента сохранён [побайтовый снимок профиля](agent-s15m-profile-before.json).

Исходный точный `source-v0-2-14/kit` и CLI не менялись. [Скрипт подготовки](agent-s15m-prepare.py) создал отдельный `same-id-different-kit-v0-2-14`: дописал в его `rules.md` инертный HTML-комментарий и обновил только соответствующий SHA в копии `manifest.json`. Release ID остался `v0-2-14`, `cli_version` — `0.2.14`. Все файлы копии соответствуют её манифесту; SHA исходных `manifest.json` и `rules.md` до/после равны. Состав и точные SHA — в [проверке пакета](agent-s15m-package.json). Эта синтетическая копия не приписывается Git SHA исходного пакета.

## Вызовы и наблюдение

[Исполнявшийся скрипт](agent-s15m-run.ps1) и [журнал команд](agent-s15m-commands.json) сохраняют точные аргументы, время UTC, коды выхода и пути сырых выводов.

1. `highgrade-v0-2-14-exact.exe global-update --profile <profile> --source <same-id-different-kit-v0-2-14> --candidate-exe <highgrade-v0-2-14-exact.exe>` без `--apply`: код 1, сырой [GlobalSameRelease](agent-s15m-preview.json).
2. Немедленно установленная CLI вызвана с `global-status --profile <profile>`: код 0, [подтверждён активный v0-2-14](agent-s15m-status-after.json).
3. SHA манифеста кандидата `b2b63079382af0b633c2e47b6f3db923c7f7f543a881cb87cb7af368126c32d9` сравнён с `manifest_sha256` проверенного журнала установки `8ae8fce4a825724697bfd6240fd1e4826f58f529a305bf05e78400f2ba344288`: **не совпали**. SHA кандидатной CLI, установленной CLI и записи журнала совпали: `0353eef50be25d04246a7f40060b84d26288d918ef27c38d21f13ec6e12209bd`. Сырые значения и решение — в [agent-s15m-decision.json](agent-s15m-decision.json).

По процедуре `GlobalSameRelease` запрещает повторное переключение, но не доказывает равенство состава. Здесь установлен выпуск с тем же ID и **другим манифестом**: вывод «этот состав уже установлен» не сделан. Повторный `apply` не вызывался; подмены release ID и перезаписи установленного выпуска не было. Для установки такого состава потребовался бы отдельно подготовленный новый выпуск, чего эта проба не разрешает.

## Неизменность и границы

[Снимок после](agent-s15m-profile-after.json) и [итоговая сверка](agent-s15m-final-verification.json) подтверждают: все 32 файла `profile`, включая `active.json` и журнал, имеют прежние SHA; статус остался v0-2-14. Исходный точный пакет сохранил байты. Проверена ветка различия **пакета при совпадающей CLI**; отдельная ветка недоступного сравнения не моделировалась. Реальный профиль, проекты, сеть, публикация и коммит не затрагивались.
