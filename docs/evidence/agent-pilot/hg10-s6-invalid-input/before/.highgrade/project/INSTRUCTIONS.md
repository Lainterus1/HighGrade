# Проектная инструкция High Grade

Подключение разрешено для этого синтетического проекта. Эта инструкция фиксирует проверенные местные факты, а не пользовательскую приёмку.

## Источники и границы

- Язык документов, планов и отчётов — русский по [правилам проекта](../../AGENTS.md).
- Назначение и действующее правило сохранности — в [README](../../README.md). В [архитектуре](../../docs/ARCHITECTURE.md) описан механизм `save`; его исходный текст сохранён в [заметке](../../notes/mechanism.txt). Проверки сохранности — в [инженерных соглашениях](../../docs/ENGINEERING.md), команды — в [документе разработки](../../docs/DEVELOPMENT.md).
- Проект — локальное синтетическое хранилище настроек. В обследованных исходниках нет установленного приложения, службы, сети или инструкции по развёртыванию. Это не доказывает их отсутствие за пределами обследованной области.
- Реестр документов и бюджетов — [documents.json](documents.json). Числовые бюджеты не согласованы; `null` означает открытое решение, а не успешную проверку.
- Формат и владение проектным каталогом спецификаций описаны в [его README](../../specs/README.md). Материалы только этого синтетического пилота собраны в [аудите и плане](../../evidence/hg9-b0/agent-audit-plan.md); каталог `evidence` хранит историю проверки, а не новое продуктовое требование.

## Маршрут работы

- Новые изменения требований веди в проектном каталоге `specs/` в нативном формате High Grade. Прежних спецификаций в обследованном проекте нет, перенос не требуется. Для неизменного контракта применяй прямую техническую работу по процедуре task установленной Поставки.
- Штатный тест: `python -B -m unittest -v` из корня по [документу разработки](../../docs/DEVELOPMENT.md). Проектный runner для `spec-run` не настроен; тест запускается напрямую. Одного структурного `doctor` или `inspect` недостаточно для проверки поведения.
- Местных навыков, пересекающихся с High Grade, в обследованном списке файлов нет. Дополнительные теги для одного небольшого домена пока не установлены.

## Полномочия и открытые решения

- В этом пилоте разрешена локальная адаптация документов и конфигурации s6; коммит, публикация, глобальное переключение и активация не разрешены. Общее право на будущие коммиты остаётся неизвестным.
- [AGENTS.md](../../AGENTS.md) запрещает публикацию. Человеческая приёмка и эксплуатационная активация не следуют из локальных проверок; их условия не определены.
- Бюджеты контекста, внешняя CI и условия эксплуатации не согласованы. Неизвестное не считай PASS и не подменяй придуманными значениями.
