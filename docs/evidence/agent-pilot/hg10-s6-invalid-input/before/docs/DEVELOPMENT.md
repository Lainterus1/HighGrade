# Подготовка и проверки

Для локальной проверки нужен Python со стандартным модулем `unittest`; отдельный список зависимостей в проекте не обнаружен. Из корня проекта запусти:

```powershell
python -B -m unittest -v
```

`test_store.py` содержит три теста: успешная запись JSON, сохранение прежних байтов при ошибке записи и при ошибке замены. Эти тесты проверяют локальное поведение `store.py`; они не подтверждают работу внешнего сервиса или восстановление после сбоя питания. Действующее правило и устройство приведены в [README](../README.md) и [архитектуре](ARCHITECTURE.md).
