# Агентный пилот High Grade: семь синтетических проектов

Автор разрешил локальный агентный пилот с процедурами Поставки и семью синтетическими проектами. Каждому агенту задана область только внутри `target/agent-pilot/sN`; данные SNAF и других реальных проектов в задания не передавались. Ни одна проба не публиковала, не активировала и не коммитила реальный Проект. Наблюдение действий агента отделено от результата Rust CLI и от приёмки человеком.

Строки описывают отдельные пробы в момент их завершения. Позднейшие задания могут менять тот же синтетический каталог; приложенные снимки фиксируют состояние соответствующей пробы. После снимка init в s7 намеренно добавлена сломанная ссылка для отдельной проверки локального принятия; она не относится к выводу о ссылках после init.

Семь частных случаев HG-0006 представлены пробами s1, вторым проходом s2, s3, s4, s5, s6 и вторым проходом s7; каждый оценивается отдельно по своим условиям. Они не подтверждают автоматически другие сценарии Поставки и не заменяют их собственные проверки.
