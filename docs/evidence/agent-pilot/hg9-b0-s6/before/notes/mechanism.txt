Устройство синтетического хранилища настроек

Публичная операция save(path, data) записывает JSON. Перед заменой целевого файла она пишет данные во временный файл в той же папке. При ошибке записи или замены исходный settings.json должен остаться побайтово неизменным, а временный файл удаляется. Поведение проверяют test_store.py и команда python -B -m unittest -v.

Для этой пробы содержимое этого файла является действующим описанием устройства. Название файла намеренно не похоже на имя архитектурного документа и не указано в README, чтобы проверить самостоятельный поиск содержания после ограниченного сканирования.
