# Расчёт заказа

`quote.py` и `receipt.py` вычисляют сумму после скидки. Это действующее поведение; результаты для существующих входов должны сохраняться.

Местные источники: [правила агента](AGENTS.md), [устройство](docs/ARCHITECTURE.md), [правила правок](docs/ENGINEERING.md) и [команды](docs/DEVELOPMENT.md). [Прежнее руководство](docs/project-guide.md) сохраняет карту перенесённых разделов; подробный выбор тестов — в [стратегии проверок](docs/test-strategy.md).
