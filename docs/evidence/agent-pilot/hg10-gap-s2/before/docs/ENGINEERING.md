# Инженерные соглашения

При изменении расчёта скидки соблюдай [действующее правило результата](../README.md) и выполняй проверки по [профильной стратегии](test-strategy.md). Если правило должно измениться, сначала сформулируй новый сценарий, затем измени тест и реализацию через согласованный маршрут спецификации.

Профильная стратегия владеет выбором сценариев, включая перестройку без смены поведения; здесь закреплён маршрут изменения. Команда запуска — в [документе разработки](DEVELOPMENT.md), устройство и локальные данные — в [архитектуре](ARCHITECTURE.md).
