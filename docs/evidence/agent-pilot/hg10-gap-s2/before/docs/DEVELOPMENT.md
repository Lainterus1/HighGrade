# Локальные команды

Штатная проверка из корня проекта требует Python со стандартным `unittest`:

```powershell
python -B -m unittest discover -v
```

Предыдущее выполнение семи тестов записано в [исходном отчёте](../test-results.txt) и [завершённом плане](../PLAN.md); текущий пилот сохраняет отдельный новый вывод в `evidence/hg9-a/`. Отдельной сборки и развёртывания в обследованном проекте нет; прежнее руководство сообщает, что внешний CI не настроен. Локальные тесты не проверяют реальные оплаты и доставку; [стратегия проверок](test-strategy.md) определяет выбор сценариев.
