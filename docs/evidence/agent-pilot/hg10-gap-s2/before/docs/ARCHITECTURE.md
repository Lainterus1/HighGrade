# Устройство расчёта заказа

`discount.py` вычисляет целочисленную сумму после скидки как `sum(prices) * (100 - discount_percent) // 100`. `quote.py` и `receipt.py` вызывают эту функцию и предоставляют `quote_total` и `receipt_total`. Действующее требование сохранять их результаты для существующих входов установлено в [README](../README.md).

`order_loader.py` читает локальный JSON и создаёт неизменяемые объекты `Order` из `order_model.py`. Поле `prices` — кортеж; `order_report.py` принимает путь и возвращает список словарей с `id`, `quote`, `receipt`. [orders.json](../orders.json) — синтетическая входная фикстура. Эти связи сверены с кодом и действующими тестами, а не выведены из имени файла.

Предыдущее смешанное описание сохранено как [карта переноса](project-guide.md). Правила изменения и проверок находятся в [инженерных соглашениях](ENGINEERING.md) и [документе разработки](DEVELOPMENT.md).
