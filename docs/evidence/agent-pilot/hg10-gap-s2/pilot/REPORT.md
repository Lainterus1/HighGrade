# HG-0010-S3/S13 — новое обязательное средство проверки

## Результат

Повторный вход в синтетический s2 выполнен через установленный High Grade v0.2.14. Принятое местное исключение разрешило прямой `unittest` при ненастроенном `spec-run` без нового вопроса. Семь штатных тестов действительно выполнились и прошли. Затем обязательная для новой задачи команда `python -m synthetic_contract_check` завершилась с кодом 1: `No module named synthetic_contract_check`. Поэтому полная совместимость, завершение зависимой проверки и пользовательская приёмка **не подтверждены**.

Исправление для зависимого шага: предоставить доступный в этой среде модуль `synthetic_contract_check` с согласованной реализацией проверки либо исправить обязательную команду на существующее средство через новое решение владельца; после этого выполнить именно утверждённую команду и пересмотреть её результат. Успех `unittest` не заменяет её. В этой пробе код, требования и проектные документы менять не поручено.

## Граница решения

Действует узкое исключение только для прямого запуска штатных тестов. Новая обязательная команда остаётся отдельным барьером. Согласно установленной процедуре совместимости, неизвестный или недоступный обязательный способ проверки оставляет пробел; останавливается только зависящее от него объявление совместимости/завершённости, а независимые чтения и штатные тесты сохранены. Структурные `bootstrap` и `doctor` не доказывают смысловую готовность; `inspect` также оставил `unknown` из-за бюджетов. Коммит, публикация, глобальная установка, запись приёмки и изменения реального проекта не выполнялись.
