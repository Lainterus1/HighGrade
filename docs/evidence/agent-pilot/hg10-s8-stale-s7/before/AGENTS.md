# Правила проекта

Язык проекта — русский. Подключение High Grade для этого синтетического проекта разрешено. Местные решения и маршрут документов — в [проектной инструкции](.highgrade/project/INSTRUCTIONS.md).

Действующее правило: счётчик никогда не выдаёт отрицательное значение. Рабочие проверки: `python -m unittest discover`. Документация может быть перестроена при сохранении исходного смысла и проверке ссылок. Внешняя публикация не разрешена.

Для инициализации, проработки задачи, изменения требований и выполнения применяй соответствующие общие навыки High Grade. Маршрут выбирай по действующей процедуре task: изменение устойчивого требования — через spec, техническое исправление без изменения контракта — через work. Проверки и ревью определяются риском.
