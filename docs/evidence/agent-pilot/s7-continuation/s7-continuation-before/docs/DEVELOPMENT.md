# Подготовка и проверки

Для работы нужен Python с модулем `unittest` из стандартной библиотеки. Отдельная установка зависимостей и запуск сервера для этого учебного проекта не предусмотрены.

Из корня проекта запусти:

```powershell
python -m unittest discover
```

Ожидаемый результат для текущего `test_counter.py` — два успешных теста: пустой список возвращает `0`, список из двух заказов возвращает `2`. Изменения поведения проверяются в этом файле; инвариант результата приведён в [инженерных соглашениях](ENGINEERING.md). Независимая [инструкция по передаче](deployment-guide.md) описывает передачу исходных файлов другому разработчику.

Каталог спецификаций High Grade — `../specs/`. При работе с требованиями используй `spec-list --root <абсолютный путь к проекту>` и выборочный `spec-read`. Штатный тест запускается напрямую приведённой командой; раннер High Grade для него не настроен.
