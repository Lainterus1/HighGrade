# Действующее устройство

`counter.py` содержит функцию `count_orders`. Она получает список заказов и возвращает длину списка. Пустой список даёт `0`. Слой хранения в этой учебной системе отсутствует.

Инвариант неотрицательного результата закреплён в [правилах проекта](../AGENTS.md) и применяется при изменениях по [инженерным соглашениям](ENGINEERING.md). Тесты находятся в `test_counter.py`; команда запуска приведена в [документе разработки](DEVELOPMENT.md). Каталог изменений требований — `../specs/`.
