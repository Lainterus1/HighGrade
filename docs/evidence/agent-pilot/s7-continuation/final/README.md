# Счётчик заказов

Учебный проект считает уникальные заказы: `count_orders` получает список строковых ID и возвращает число различных ID. Повтор одного ID учитывается один раз, пустой список даёт `0`. Серверного развёртывания у примера нет.

Документы проекта: [правила агента](AGENTS.md), [устройство](docs/ARCHITECTURE.md), [инженерные соглашения](docs/ENGINEERING.md), [подготовка и проверки](docs/DEVELOPMENT.md). [Обзор](docs/overview.md) указывает на разделённые документы. Отдельная [инструкция по передаче](docs/deployment-guide.md) сохранена.

Изменения требований ведутся в проектном каталоге `specs/` через High Grade. Каталог принадлежит проекту и сохраняется при смене процесса работы; исходный порядок чтения и местные решения описаны в [проектной инструкции](.highgrade/project/INSTRUCTIONS.md).

Для работы с исходниками см. [команды разработки](docs/DEVELOPMENT.md).
