# Проектная инструкция High Grade

Подключение и перестройка документации разрешены в [правилах проекта](../../AGENTS.md). Эта инструкция фиксирует проверенные местные решения; создание конфигурации само по себе не является пользовательской приёмкой работы.

## Проект и документы

- Язык авторских документов, планов, состояния и передачи человеку — русский по `AGENTS.md`. Технические имена, команды и машинные значения остаются исходными.
- Назначение и границы — [README](../../README.md). Это учебный счётчик заказов без слоя хранения и без развёртывания на сервере.
- Действующие источники: [правила агента](../../AGENTS.md), [устройство](../../docs/ARCHITECTURE.md), [инженерные соглашения](../../docs/ENGINEERING.md), [подготовка и проверки](../../docs/DEVELOPMENT.md), [справка по передаче](../../docs/deployment-guide.md). [Прежний обзор](../../docs/overview.md) оставлен как навигация.
- Действующий инвариант: счётчик не выдаёт отрицательное значение; источник — `AGENTS.md`.
- Реестр документов и бюджетов: [documents.json](documents.json). Числовые бюджеты не согласованы; `null` в реестре означает открытое решение, а не успешную проверку.

## Маршрут работы

- Новые изменения требований хранятся в проектном каталоге `specs/` в нативном формате High Grade. Каталог принадлежит проекту. Прежнего каталога спецификаций в обследованных файлах нет; массовый перенос не нужен.
- Для задач применяй процедуру task активной поставки: устойчивые изменения требований — через spec; технические изменения при прежнем контракте — через work. Зависимая техническая работа требует одного плана. Готовность и решение человека проверяются отдельно.
- Навигационные теги пока не заведены: у малого проекта одна предметная область. Связи требований добавляются по фактической необходимости.
- Штатные проверки и порядок запуска описаны в [DEVELOPMENT](../../docs/DEVELOPMENT.md). Раннер `spec-run` не настроен; тесты запускаются напрямую.
- Местных навыков, дублирующих High Grade, в обследованном проекте нет.

## Полномочия и ограничения

- Для исправления ссылки в `README.md` на `docs/DEVELOPMENT.md` разрешён один локальный коммит. Иные коммиты требуют отдельного поручения; публикация и глобальное переключение High Grade не разрешены.
- Локальная активация через `highgrade-approve` здесь неприменима: счётчик не имеет установленного приложения или службы.
- Внешняя публикация запрещена `AGENTS.md`; `highgrade-push` не выполняется.
- Отчёты `doctor` и `inspect` подтверждают только указанные ими технические свойства. Исполнение тестов и смысловая сверка документов нужны отдельно.
