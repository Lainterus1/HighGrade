# Расчёт заказа

`quote.py` и `receipt.py` вычисляют сумму после скидки. Это действующее поведение; результаты для существующих входов должны сохраняться.

Устройство, правила правок и команды пока находятся в [старом руководстве](docs/project-guide.md). Подробный выбор тестов — в [стратегии проверок](docs/test-strategy.md).
