# Руководство по проекту расчёта заказа

## Устройство

`order_loader.py` читает `orders.json` и собирает предметный объект из `order_model.py`. `discount.py` вычисляет скидку, `quote.py` возвращает предварительную сумму, а `receipt.py` формирует итоговый чек. `order_report.py` собирает сводку. Действующий инвариант: для существующих входов сумма после скидки не меняется от организационной перестройки документов.

## Правила разработки

Менять расчёт скидки следует вместе с проверкой сумм и чека. Сохранять значения исходных входов; если правило меняется, сначала сформулировать новый сценарий и затем обновить тест. Данные `orders.json` — синтетическая локальная фикстура.

## Команды

Запуск проверок: `python -B -m unittest discover -v`. Отдельной сборки и развёртывания у проекта нет; внешний CI не настроен.

Профильная [стратегия проверок](test-strategy.md) уточняет выбор сценариев и остаётся самостоятельным документом.
