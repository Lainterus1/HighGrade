# Стратегия проверок расчёта заказа

Этот документ отвечает за выбор проверок, а не за команды запуска или устройство модулей. Для изменений суммы проверять как итог `quote.py`/`receipt.py`, так и исходные позиции заказа. Для рефакторинга без смены поведения сначала сохранять тесты на существующих входах. Внешних интеграций в синтетической фикстуре нет.

Штатная команда находится в основном документе команд после адаптации. Не приписывать локальным тестам проверку реальных оплат или доставки.
