# Действующее устройство

`store.py` содержит публичную операцию `save(path, data)`. Она сериализует данные в JSON, пишет их во временный файл в каталоге целевого файла и затем заменяет целевой файл через `os.replace`. Если запись или замена завершается ошибкой, временный файл удаляется. Существующий `settings.json` остаётся побайтово неизменным; исходное правило записано в [README](../README.md).

Описание устройства перенесено по смыслу из [исходной заметки](../notes/mechanism.txt) и сверено с `store.py` и `test_store.py`. Заметка сохранена как источник. Проверки и команда запуска — в [документе разработки](DEVELOPMENT.md). Гарантии восстановления после сбоя питания и работа внешнего сервиса в проекте не заданы.
