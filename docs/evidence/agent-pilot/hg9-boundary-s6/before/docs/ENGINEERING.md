# Инженерные соглашения

При изменении сохранения настроек соблюдай [действующее правило сохранности](../README.md): ошибка сохранения не меняет байты прежнего `settings.json`. `test_store.py` проверяет невалидный ввод, ошибку после записи во временный файл, ошибку `os.replace` и удаление временного файла при ошибках записи и замены.

Штатный тест запускается по [инструкции разработки](DEVELOPMENT.md). Другие правила формата, эксплуатации и совместимости для этого синтетического проекта не установлены; не выводи их из текущей реализации.
