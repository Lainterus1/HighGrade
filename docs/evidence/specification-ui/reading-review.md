# Компактное представление спеки

Изменение по запросу пользователя: сценарии и задачи скрыты в карточке; редактор показывает условия готовности, сохраняя остальные поля сценария. Цель, требования, границы и все условия готовности представлены компактной сеткой с усиленной иерархией текста. Исходные тексты не пересказываются.

Проверено:
- Frontend, release binary и Storybook собраны.
- 15/15 браузерных сценариев native/edit прошли, включая изменение условия готовности с сохранением остальных данных, CAS, переключение и восстановление позиции.
- Живой проект: desktop 1440 и mobile 390, без горизонтального переполнения, ошибок страницы и записей. Все 10 условий доступны; диалог приёмки 402 px.
- 200 входных файлов неизменны до и после проверок: reading-inputs.json.
- git diff --check пройден.

Артефакты: reading-playwright.json, reading-live.json, reading-live.png, reading-mobile.png, reading-dialog.png.

Коммит, глобальная активация, публикация и приёмка не выполнялись.

Независимое ревью review_ui_refinement: REVIEW_GO, замечаний нет. Подтверждены 15 сценариев, 200 хешей, сохранность полей сценариев и мобильный просмотр. Прежнее ограничение: неполные скрытые обязательные поля исправляются через CLI/агента.
