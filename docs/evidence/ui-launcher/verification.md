Проверена рабочая редакция Linux из identity.json. Полный Nextest: 216 passed, 0 failed/skipped (tests-verified.txt и junit.xml); снимок до запуска — attempt.json, завершение — completion.json. Изменения UI предыдущих задач сохранены.

## Наблюдения

- S1: реальный установленный тестовый бинарник запущен через .sh, сервер вернул правильный корень; повторено после переноса в путь с кириллицей, пробелами, &, !, %, апострофом. Сервер остановлен через API.
- S2: preview не пишет; apply повторяем; чужой файл и ссылка сохранены; отсутствующий файл восстанавливается, разрешение исполнения исправляется. Нет установки — понятная ошибка. Doctor проверен без PATH; Init нормативно вызывает preview/apply, агентный Init-пилот не проводился.
- S3: тот же запускатель работает после реального global-update в изолированном профиле; несовместимый кандидат без launcher_protocol отвергается; отдельный сбой postcheck возвращает предыдущий выпуск и запуск снова работает. Это восстановление неудачной транзакции, а не откат успешного обновления.
- Исходные шаблоны закреплены LF; генерируемый batch CRLF. Дополнительные сборки UI/Node для запуска не нужны.
