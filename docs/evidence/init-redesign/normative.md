# Нормативная сверка инициализации — 2026-09-26

Метод: чтение HG-0045–HG-0047, init, audit, справочника survey, шаблона местной инструкции и действующих владельцев High Grade. Проверяется содержание маршрута, без заявления об исполнении будущим агентом. Автоматические результаты — junit.xml; входы до запуска — run-inputs.json, области сценариев — input-scopes.json.

| Условие | Проверенный результат |
|---|---|
| Новый проект | Предполагаемое и неприменимое различаются; начальные решения unknown; specs/реестр до обследования не требуются. Команды не выдумываются. |
| Существующий проект | Обзор согласованной области; чтение по влиянию на адаптацию и риск. Имя документа не доказывает содержание; владельцы переиспользуются. |
| Частично известные ответы | Семь решений проверяются до глубокого чтения; спрашивается только неизвестное или существенное противоречие; основание сохраняется. |
| Нет полномочий на изменение | Обследование/план не разрешают адаптацию; строго read-only оставляет результат в ответе. Запись survey не разрешает менять продукт. |
| Неизвестен внешний deploy | Не препятствует разрешённой локальной работе. blocks перечисляет зависимые действия; действия вне поручения остаются ограничением. |
| Независимая непрочитанная область | Остаётся неизвестной без blocks; обзор не объявляется прочтением. Частичный технический снимок не подтверждает готовность. |
| Адаптация определена и разрешена | Дополнительное формальное согласование не требуется. Спека владеет задачами; survey хранит ссылку и продолжение. |
| Сбой/прерывание | next и stage отражают фактическое состояние. Атомарность защищает один JSON, общая транзакция проекта не обещается. |
| Отрицательное ревью | Актуальное no_go запрещает переходы. Валидная структура не удостоверяет смысл или человеческую приёмку. |
| Повторный init | Обычный inspect использует реестр. Reopen сохраняет завершённую редакцию и решения, сбрасывает снимок/ревью. Смена Git SHA не отменяет решения. |
| Обычная задача после init | Знания переданы владельцам; исторический survey не становится обязательным контекстом или вторым backlog. |
| Редактура правил | Достаточны смысловая сверка, генерация/ссылки/inspect; агентные упражнения на импровизированных проектах не обязательны. |

## Сквозная навигация High Grade

Прочитанные владельцы: README — цель; AGENTS и .highgrade/project/INSTRUCTIONS.md — полномочия; docs/ARCHITECTURE.md — модули; docs/ENGINEERING.md — инженерные правила; docs/DEVELOPMENT.md — команды и проверки; .highgrade/project/documents.json — роли и бюджеты. Их перенос не нужен. Проект уже подключён; повторная миграция его настроек не проводилась.

Характерный запрос: сохранить обследование и продолжить после изменения источника. Требования — HG-0045-S3/HG-0046-S2; реализация — src/survey.rs и src/discovery.rs; проверки — survey_tracks_only_selected_sources_and_preserves_completed_history и discovery_limits_and_missing_sources_are_explicitly_incomplete в tests/survey_contracts.rs; готовность — существенное изменение видно, посторонний файл не обесценивает снимок, история и решения сохраняются. Это документальный разбор навигации; исполнение тестов подтверждает JUnit.

HG-0047-S3: установленная фикстура отдельно проверяет доступность схемы, шаблона и процедуры без исходного репозитория. HG-0028-S3 сохранён: предварительная диагностика не требует переносить исправные документы либо вести дублирующую таблицу. Проверены правила, не поведение модели на стороннем продукте.

## Области доказательств

HG-0045/0046 зависят от Rust CLI, зависимостей и survey_contracts: учитывается весь src, Cargo, конфигурация и поддержка фикстур. HG-0047-S3 дополнительно зависит от kit и установочного контракта. Нормативные HG-0047-S1/S2 и HG-0028-S3 учитывают владельцев опроса, адаптации и проверки. Общий снимок запуска шире сценарных областей. Старые несвязанные доказательства и человеческие решения не обновляются автоматически.
