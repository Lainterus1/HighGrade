# Исправления и выборочная очистка diff

Область: два дефекта из анализа diff, выбранные большие ответы CLI и повторы правил. Один Goal создан по явному запросу пользователя. История, приёмка и полезные тесты сохраняются. `presentation` исключён. Этот результат не завершает прежний комплексный Clear и не сертифицирует все методы проекта.

## Исправления и исполнение

- `clear_batch.py` запрещает root `.hg-clear-report.json` без учёта регистра до чтения входов и создания output. Реальная регрессия сначала выявила два разрешённых alias, затем прошла для трёх вариантов имени. Она проверяет отказ до output и сохранность исходных байтов. Это Linux исполнение переносимой проверки имени; фактический Windows filesystem не проверен.
- `trace` снимает неоднозначную связь Rust source→binary. Третья suite не восстанавливает её. Новая регрессия сначала показала ложный сценарный PASS, затем подтвердила `unknown`, независимый PASS и ручной сценарий вне automatic trace. Она выполнена отдельно и в полном Nextest.
- Planner остаётся владельцем Goal policy. Review владеет методом проверки тестов. Удалены повторы и две строки дублирующего renderer assertion; все существовавшие тестовые функции сохранены. Generated skills и manifest обновлены штатным генератором. Helper остаётся необязательным для совместимых случаев; controlled edits допустимы.

Финальный Nextest: **242 PASS, 0 skipped**, запечатанный before/after набор. Trace: **145/145 связанных сценариев PASS**, 187 вне automatic trace; 154 связанных и 88 несвязанных тестовых случаев. Python проекта: **82 PASS**. После финальных правок references повторён затронутый helper suite: **12 PASS**; его before/after inputs совпадают. Node guards: **4 тестовых файла PASS**, без skips. Формат, renderer, структура, native validation и inspect проходят; inspect имеет 11 ExternalLinkUnchecked, без failed/unknown. Маршрут **95 346 / 95 600 bytes**; бюджет не повышен.

Два настоящих `spec-run` повторили исторические exact selectors HG-0024-C1 и HG-0076-C1. Их raw logs сохранены в `specs/changes/*/evidence/`. HG-0024-C1 не исполнял новую ambiguity-регрессию: её доказательство — отдельный RED/PASS и Nextest JUnit. HG-0076-C1 проверил установку helper в изолированный профиль и работу после удаления исходной копии. Helper suite дополнительно проверил actual assertions, survivor→strengthened, invalid outcomes, stop/preservation, causal reuse и контроль 9→5 команд. Эти наблюдения обновляют только соответствующие сценарии; старые actor/review результаты не переносятся как новый полный PASS.

## Очистка и пределы

22 новых полных ответа CLI, **174 221 961 bytes**, исключены из Git selection. Полные неизменённые байты и два прежних manifest доступны в `.highgrade/local/diff-cleanup-2026-10-14/recovery/`; они не входят в Git. Их исходные local sources тоже сохранены. CAS manifest пересозданы с новыми SHA: audit 304→284 selections, task 7→5. Индекс audit обновлён. Необходимые 26 исходных runner logs и все native history/runs/acceptance сохранены. Исторические inventories не переписывались: они описывают прошлый состав файлов.

Проверки сначала обнаружили отсутствие Nextest в PATH, запрет sandbox открыть локальный UI порт и неверный fragment моей новой ссылки Work storage. Это разные причины; исходные ошибки сохранены. PATH исправлен, локальный порт проверен в разрешённой среде, fragment исправлен и проверен узким тестом. Финальный полный прогон прошёл.

Оригиналы, выбранные snapshots, nested reports, reviews и производные краткие receipts перечислены в [индексе](verification.json). Derived receipts не заменяют raw reports. Автоматические тесты не доказывают надёжность будущих действий модели. Новый actor replay, Windows CI, exact-SHA установленный выпуск и человеческая приёмка не выполнялись. Tool/environment identity и ancestor/home Cargo settings не объявлены полностью запечатанными. Коммит, активация и push не назначены.
