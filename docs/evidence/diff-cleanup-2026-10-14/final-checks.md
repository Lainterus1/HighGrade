# Итоговое уточнение проверок и хранения

[Первый отчёт](checks.md) сохранён неизменным, так как на него уже записаны native evidence. Этот документ уточняет последующую проверку Node и обслуживание; код, правила и исходные Rust/Python результаты не изменялись.

Sandbox возвращал EPERM для вложенного `spawnSync` Node. Его начальный runner показал четыре успешных file containers, но не подтвердил исполнение отдельных случаев. Это не доказательство полного прохождения Node guards. Проверка повторена в разрешённой среде на штатном Node 24.19.0: **14 реальных случаев PASS, 0 skipped/failed/cancelled**. Исходный слабый сигнал сохранён; он не переименован в полноценный PASS.

На том же Node 24 отдельно прошли scale и reuse. Scale проверил 100/200 требований, выбор одной области, неверные/отсутствующие/лишние markers и дубликаты. Reuse подтвердил эквивалентную метадату, relocation с исходным capture root и отказ после изменения сценария, Rust source/hash и toolchain. Повторные native validation, inspect, renderer, format и diff проходят. Inspect: 11 ExternalLinkUnchecked, без failed/unknown; маршрут 95 346 bytes.

После проверенного экспорта выбранных оригиналов удалены пять собственных запечатанных managed runs. Семь прежних неизвестных/прерванных runs сохранены. Cargo debug/test cache удалён штатным `target-maintenance --cache debug`; текущий CLI предварительно сохранён и восстановлен с тем же SHA-256. Candidate, tools и build-cache сохранены. `target` — **365,07 МиБ**, ниже 600. Полный maintenance check всё ещё exit 2 из-за сохранённого чужого `hg58`; это не PASS общей очистки.

Formal spec-review записан по реальному независимому GO только для данного локального среза. Прежняя история, runs, input manifests и human acceptance сохранены. Семь direct records относятся к фактически повторённым HG-0076-S5…S10 и HG-0024-S3; прежние actor/Windows методы не объявлены повторно выполненными. `presentation` не читался и не менялся.
