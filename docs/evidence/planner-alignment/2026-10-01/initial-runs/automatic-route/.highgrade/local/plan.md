# Автоматически выбранная техническая координация alpha → beta
Поручение: «Исправь нормализацию меток по README, затем обнови пример README; выполни и проверь оба зависимых этапа по местной инструкции. Коммит, активацию, публикацию и приёмку не поручаю».

Местная инструкция назначает маршрут Planner для зависимой цепочки. В запросе нет поручения Goal; автоматический выбор маршрута сам такого полномочия не даёт. Goal-инструменты также отсутствуют. Используется обычный план.
1. Alpha: воспроизвести существующую ошибку unittest, исправить app.py по контракту README, получить успешный python -m unittest discover -s tests -v.
2. Только после alpha: изменить пример README, выполнить python tools/check_docs.py.
3. Сопоставить оба независимых evidence с текущими входами и проверить сохранность colleague.txt, HEAD/индекса и иных tracked файлов. Коммит, активация, публикация и приёмка исключены.
