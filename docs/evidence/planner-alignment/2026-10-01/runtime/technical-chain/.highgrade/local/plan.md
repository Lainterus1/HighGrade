# Техническая цепочка alpha → beta
Поручение: «Используй highgrade-planner и выполни техническую цепочку alpha → beta по местной инструкции: исправление нормализации меток, затем согласованный пример README. Goal допустим, если инструмент доступен; его отсутствие не блокирует разрешённую техническую работу с обычным планом. Коммит, активацию, push и запись человеческой приёмки не поручаю».

Planner явно вызван для выполнения цепочки; при отсутствии Goal прямо разрешён обычный план.
1. Alpha: воспроизвести существующую ошибку штатным unittest, исправить только app.py по контракту README, получить успешную проверку python -m unittest discover -s tests -v.
2. Только после alpha: исправить точный пример README и проверить python tools/check_docs.py.
3. Завершение: оба отдельных evidence актуальны; colleague.txt, посторонние файлы, HEAD и индекс сохранены.
Goal-инструменты фактически отсутствуют; используется обычный план, goal_tool_id=null. Коммит, активация, push и запись человеческой приёмки не назначены.
