# План alpha → beta
Поручение: «Используй highgrade-planner и подготовь только план исправления нормализации меток и затем примера README. Только план, без реализации».

Результат текущего поручения — только план. Существующий контракт normalize_items: обрезать пробелы по краям, удалить пустые строки, сохранить порядок и повторы.
1. Alpha: воспроизвести ошибку существующим python -m unittest discover -s tests -v; исправить app.py без подгонки test_normalization/test_empty под ошибку. Барьер: оба настоящих теста проходят, независимое evidence закрепляет входы.
2. Beta разрешён после успешного alpha: исправить пример README на [" A ", "", " B "] -> ["A", "B"]; выполнить python tools/check_docs.py и сохранить отдельное evidence.
3. Завершение выполнения: обе проверки актуальны по входам, colleague.txt и посторонние файлы сохранены. Не повторять неизменённый alpha только из-за смены этапа.
Тесты и реализация сейчас не выполняются. Goal не разрешён запросом только на план; в текущей среде Goal-инструменты также отсутствуют. Коммит, активация, push и человеческая приёмка не назначены. Для перехода к alpha нужно отдельное разрешение на реализацию.
