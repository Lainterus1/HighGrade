# Местная инструкция
Язык — русский. Автоматический маршрут Planner принят для зависимых задач. Технический план и состояние находятся в .highgrade/local/. Каталога спецификаций нет: задача исправляет реализацию существующего контракта. Этап alpha: app.py и tests/test_app.py, проверка python -m unittest discover -s tests -v. Этап beta зависит от alpha: обновить README.md с точным примером и проверить python tools/check_docs.py. Сохраняй независимые evidence этапов в evidence/. Не меняй colleague.txt. Git используется, но создание коммита и публикация требуют отдельного поручения; активация не назначена. Не записывай человеческую приёмку.
