# HG-0066: проверка состава публикации v0-3-9

Вид проверки — нормативная сверка всех десяти сценариев и проверка технического состава для коммита, локальной активации и прямой публикации в main по поручению автора от 2026-10-01. Основа — `d195324e67a42ca0ed117b131aad15809815cf03`, незакоммиченное дерево. Источники нормы — [Work](../../../kit/procedures/work.md#проверка-до-изменения-реализации), [ревью](../../../kit/references/review.md), [Spec](../../../kit/procedures/spec.md) и [проектный пример](../../DEVELOPMENT.md#сценарии-и-исходные-результаты). Номер выпуска — новый v0-3-9, версии Cargo/манифеста совпадают; Rust-поведение и формат каталога не изменены.

Прежние отчёты сохранены с теми же байтами в постоянном месте: [карта переноса и SHA](original-relocation.json), [исходная нормативная сверка](original-verification.txt), [исходное независимое ревью](../../reviews/test-before-implementation-original.txt). Исходный failed sandbox остаётся failed; перенос не подтверждает актуальность прежнего результата. Новая запись evidence использует этот отдельный отчёт и фактические текущие причинные входы. Постоянные исходные данные лежат в publication-raw; target остаётся рабочим каталогом.

## Причинные входы

Для HG-0026-S1 существенны Work, DEVELOPMENT и QUALITY; для HG-0026-S2 — Work. HG-0066-S1 использует Work и существенные нормы контракта/полномочий rules, task и spec. HG-0066-S2/S3 — Work. HG-0066-S4/S5 дополнительно используют справочник verification, определяющий фактическое наблюдение и запись исходов. HG-0066-S6 — метод ревью, Work и Spec. HG-0066-S7 — Work, Spec, QUALITY и общие полномочия. HG-0066-S8 — Work, ревью, DEVELOPMENT, генератор, сгенерированный навык, манифест и исходный результат проверки их согласованности. Новая версия манифеста требует новой сверки S8; перенос отчёта требует новой записи всех ссылающихся нормативных сценариев.

Общий снимок восстановления состава хранится отдельно; его файлы не становятся входами каждого сценария. Редакцию требования связывает CLI. Перед записью доказательств должны совпасть снимки до/после и хеши фактически сверенных причинных источников.

## Предел и дальнейшая передача

Нормативная сверка здесь проведена повторно для текущих источников с теми же согласованными исходами. Хеши kit/manifest и сгенерированного Work согласованы; проверка CLI/установки — отдельный технический прогон, который не подтверждает будущее исполнение инструкции агентами. Независимый вердикт будет записан после актуальных evidence. Коммит, сборка кандидата из SHA, preview/apply, global-status и exact-SHA Windows/Ubuntu CI ещё не выполнялись этой записью; их фактические результаты сохраняются отдельно. Человеческая приёмка не вытекает из порученной активации или публикации.
