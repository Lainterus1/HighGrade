## Причинные входы

Входы ручного evidence выбираются по проверяемой норме, без всего дерева CLI. Для HG-0026-S1 существенны Work и матрица DEVELOPMENT; для HG-0026-S2 — правила повторов Work. HG-0066-S1 использует Work и существенные нормы контракта/полномочий из `kit/rules.md`, `task.md` и `spec.md`. HG-0066-S2/S3 проверяются по Work. HG-0066-S4/S5 дополнительно используют `kit/references/tools/verification.md`, определяющий исполнившееся наблюдение, исходы и неизменяемость записанных доказательств. Для HG-0066-S6 существенны метод ревью, Work и Spec. Для HG-0066-S7 — Work, общие полномочия, Spec и QUALITY, различающие содержание правила и наблюдение модели. Для HG-0066-S8 — Work, ревью, DEVELOPMENT, генератор, сгенерированный навык, манифест и исходный результат проверки их согласованности.

Общий снимок содержит также местную инструкцию, инженерные правила и конфигурацию структурных проверок. Он нужен для восстановления области проверки и не заменяет причинные входы отдельного сценария. Редакцию самого требования закрепляет CLI; `spec.json` и весь изменяемый каталог не добавлены в байтовые входы во избежание самоссылки при записи доказательств.
