# Хранение результатов и приёмка: текущая проверка

Дата: 2026-10-09. Проверено локальное дерево перед кандидатным коммитом. Финальный exact-SHA Windows/Ubuntu CI и installed E2E не исполнены; HG-0070-T6 открыт. Активация, публикация и новая человеческая приёмка не выполнены.

## Исправления и наблюдения

Штатный tests создаёт управляемый запуск и сохраняет текущие Nextest-файлы, включая неуспех. Браузер пишет JSON и вложения внутрь своего запуска. Экспорт принимает вложенный nextest/run.json, но отвергает состояние обёртки. После закрытия команды и лога завершённый запуск освобождает владельца; активные и прерванные остаются защищены. Rust и Playwright требуют служебный токен своего запуска; чужой активный контекст отвергается до команд и записи.

Приёмка неизвестного build ID использует однозначные сохранённые сведения того же снимка и закрывает оба обращения. Повтор не создаёт решение; чужая версия отвергается. Метка проверенной редакции удаляется только целиком; URL, refs и нераспознанный текст сохраняются. Форма содержит статус и необязательный комментарий; LLM не вызывается.

## Практическое хранение

Из исходных 78 файлов удалены 73 лишние рабочие копии (1 668 000 байтов). Все исходные байты предварительно сохранены локально для восстановления; нужные исторические наблюдения экспортированы в [комплект](../objects/bd50adac98774e3cbbf4703756cc6badb1be22c8c7e1621c5521755b664b073d.json). Пять исходников оставлены на прежних путях для неизменённой истории evidence: JUnit, UI JSON, прежняя сводка, конфигурация и ревью. Эти исторические сведения не подтверждают текущую редакцию. Два машинных отчёта используют существующий highgrade-evidence attribute: их байты сохраняются, подробный diff доступен через --text. Старые имена внутри прежней сводки относятся к первоначальному запуску; выбранные сохранившиеся файлы доступны по origin-именам манифеста.

Все выбранные манифесты проверены штатным verify. Повтор такого же экспорта переиспользует содержимое. finish успешно экспортировал и собрал завершённые новые запуски. Старые sandbox-запуски с неоднозначным PID сохранены в игнорируемом target; владение не сбрасывалось вручную. Ненужные прежние попытки, прерванные и неизвестные данные не удалены по возрасту. 34 файла presentation/ совпадают с исходными хешами и остаются вне задачи.

Пределы: чтение правил не доказывает их универсальное исполнение агентом. Наблюдён штатный маршрут и его применение здесь. Нового hook, общего запрета для подключаемых проектов или дополнительного CI-барьера не вводилось. Проверка выпуска остаётся отдельным незакрытым критерием.
