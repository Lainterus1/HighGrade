## Основание областей доказательств

`run-inputs.json` — сохранённый общий снимок до/после 158 Rust и 15 Python тестов. `input-scopes.json` — план перед запуском. При ревью HG-0038-S1 добавлена непосредственно подключённая `include_bytes!` fixture store.json; она уже была в полном снимке прогона. Исправленный список — `scenario-inputs.json`.

Для каталога сохранены модули specs, CLI/общие пути/trace/package/install, Cargo, Nextest и test support; для issue-сценариев добавлены issues и issue_contracts. При проверке установки сохранены весь src и kit, поскольку глобальные команды и проверка манифеста имеют общие зависимости. Для нормативных сценариев перечислены владельцы правил. Очистку подтверждают фактический Python-прогон и два исходных файла. Поэтому изменение постороннего проектного документа не делает все сценарии каталога устаревшими. Неизвестные общие зависимости не исключались ради получения PASS.

После полного прогона изменены только BUILD (уточнение явной версии) и проверочный `check-scenario-scale.mjs`. Первый перечитан в этой сверке, второй повторно запущен для 100/200 спецификаций; также прошёл reuse guard. Отдельные отпечатки и исходные результаты сохранены. Rust, его конфигурация, Python-реализация очистки и тесты не менялись; повтор этих прогонов не нужен.

Предел: Python очистка не транзакционная при ошибке Cargo во время исполнения; предупреждение есть в BUILD. Проверки не устанавливают устойчивость поведения модели и не закрывают неизвестные сценарии старых спек.
