## Изменение и границы

Lora 600 для заголовков, Manrope для текста и управления; тёплая рабочая область, светлая поверхность документа, тонкие границы, единая геометрия кнопок/полей/диалогов. Исходный [референс](concept-reference.png): средняя колонка. Изображение задаёт направление, не новые поля или сокращение документа. Функциональные TSX-компоненты, fixtures, API и Rust-логика не изменены. Логотип и семантика иконок сохранены.

Истории используют прежние общие компоненты. Цветовые образцы Основ берут CSS-переменные из theme.css вместо копий палитры. Manrope/Lora и OFL доставляются локально; манифест связывает каждый шрифт со своей лицензией. Источник и SHA Lora — в ui/licenses/README.md.
