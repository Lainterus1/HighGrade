# v0-3-5: проверка объединённого состава

Проверено 2026-09-30 на рабочем дереве `main` после объединения HG-0059 и переработки процедуры `work`. Зафиксированного SHA и локальной активации на момент этих проверок ещё нет; проверка установленного кандидата выполняется после коммита.

| Область | Фактический результат | Исходное доказательство |
|---|---|---|
| Rust | Nextest 190/190, без пропусков; `cargo build --locked`, `cargo fmt --check` прошли | [Nextest](nextest-run.json), [JUnit](nextest-junit.xml) |
| Сценарии исходников | `source-scenarios check`, подготовка, trace и verify: 115/115 автоматических сценариев | [trace](trace.json) |
| Интерфейс | TypeScript/Vite и Storybook собрались; Playwright 26 прошли, один сценарий установленной версии ожидает точного SHA | [полный Playwright](playwright-final.json) |
| Установка общего набора | 28/28 `global_contracts` после добавления `references/review.md`; текущий CLI читает состояние установленного v0-3-4 | [Nextest](nextest-run.json) |

Первый полный Playwright [завершился 18 pass, 8 fail, 1 skip](playwright-all.json): восемь Storybook-сценариев не смогли подключиться к серверу, который не был запущен. После сборки Storybook и запуска локального сервера повторный полный прогон прошёл без ошибок. Отчёт первой попытки сохранён без изменения; это ошибка подготовки проверки, не дефект проверяемого поведения.

Новый `kit/references/review.md` первоначально не проходил строгую проверку материалов установленной поставки. Исправлена упаковка текущего выпуска с сохранением чтения предыдущего журнала установки; после исправления повторены Nextest, сборка и проверка сценариев. Хеши `Cargo.toml`/`Cargo.lock` сменились при выпуске 0.3.5, поэтому доказательства семи сценариев HG-0059 записаны заново из отчётов этого прогона. Независимый субагент повторно проверил объединённый состав и дал `REVIEW_GO`; `spec-review` записан для новых доказательств, `spec-check` показывает `technical=ready`, `review=go`, `human=pending`.

Отчёт Nextest содержит 362 отпечатка исходников. После прогона изменился только `specs/catalog.json`: в него записана привязка семи сценариев к самому отчёту и новым исходным хешам. Исполняемый код и тесты совпадают с отчётом; каталог не указан среди входов этих семи сценариев. Требование совпадения отпечатка каталога с отчётом создало бы цикл записи доказательства.

Этот документ описывает локальные проверки исходного состава. Коммит, установленный E2E, активация, push, удалённый CI и человеческая приёмка имеют отдельные результаты.
