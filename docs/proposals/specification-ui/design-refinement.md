# Уточнение оформления: Manrope и адаптация Lucide

Пользователь согласовал браузерный образец и поручил добавить уточнения до начала реализации. Нормативные требования — HG-0054-R1/R3/R6 и HG-0057-R1; этот файл хранит происхождение визуального ориентира, не второй набор требований.

[Образец](manrope-lucide-reference.png) отрисован в браузере с настоящим локальным Manrope и SVG. Внизу — исходные Lucide и предлагаемые геометрические адаптации основных четырёх знаков. Данные/счётчики демонстрационные. Экран — изолированная проба HTML/CSS, не выполненный React/shadcn-интерфейс и не доказательство исполнения спек.

- Шрифт: Manrope, кириллица/латиница; 400 для текста, 550 для навигации, 700 для заголовков. [Источник Google Fonts](https://github.com/google/fonts/tree/main/ofl/manrope), [OFL](https://github.com/google/fonts/blob/main/ofl/manrope/OFL.txt).
- Иконки: [Lucide](https://lucide.dev/), [правила геометрии](https://lucide.dev/contribute/icons/specification), [лицензии](https://lucide.dev/license). База образца: files, message-square, clock-3, circle-check; четыре адаптации имеют собственную геометрию. Для поиска/редактирования/папки/стрелки сохранены знакомые силуэты и общая толщина линий.
- Сетка 24×24, номинальная линия 1,75 px, мягкие углы/окончания. Размеры и читаемость проверяются на реальных SVG при реализации; оформление не доказывает юридическую исключительность символов.
- В приложении и Storybook используются одни локальные ресурсы, без CDN. Конкретные версии/отпечатки и применимые уведомления закрепляются при подготовке финальных assets.
- Геометрический логотип в этом образце — эскиз. Финальный знак по-прежнему создаётся из выбранного варианта 10 через SVG Vectorizer; [лист финалистов](logo-finalists-reference.png) остаётся его источником.

По типографике и иконкам этот образец уточняет ранний [макет экрана](ui-reference.png). Согласованная логика состояний и остановка после HG-0054 не меняются.
