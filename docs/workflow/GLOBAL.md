# Глобальный workflow High Grade

Назначение: границы продукта и навигация Проекта. Опубликованная Поставка — [v0-2-10](../releases/v0-2-10.md); [план самостоятельности](../plans/2026-09-24-portable-delivery.md) завершён. Установленный выпуск показывает `global-status`.

## Область документа

**Поставка** — переносимый набор навыков, процедур, шаблонов и CLI. **Проект** — этот репозиторий её разработки. **Подключаемый проект** — внешний проект, который она адаптирует. Поставка должна работать без доступа к Проекту; её общие правила принадлежат `kit/`, местные решения — подключаемому проекту. История решений — в [SPECIFICATION](SPECIFICATION.md).

## Владение и границы

Восемь общих навыков и CLI устанавливаются в профиль пользователя. Подключаемый проект хранит свою `.highgrade/project/INSTRUCTIONS.md`, документы, OpenSpec, тесты и доказательства. Центрального списка проектов нет. SVG Vectorizer и Code Health Audit — отдельные пакеты.

## Пользовательский маршрут

[Общие правила](../../kit/rules.md) определяют маршрут. [Init](../../kit/procedures/init.md) адаптирует проект; [task](../../kit/procedures/task.md) уточняет задачу; [spec](../../kit/procedures/spec.md) оформляет поведение; [work](../../kit/procedures/work.md) выполняет и проверяет. Малые ясные технические задачи имеют сокращённый путь.

[Approve](../../kit/procedures/approve.md) принимает точный состав локально; [push](../../kit/procedures/push.md) отдельно публикует выбранный диапазон. [Clear](../../kit/procedures/clear.md) — обзор по запросу; [update](../../kit/procedures/update.md) — отдельное обновление установки. Процедуры владеют подробными правилами и полномочиями, этот документ их не дублирует.

## Инструмент и доказательства

[Справочник CLI](../../kit/references/cli.md) описывает установку, обновление и read-only диагностику. Штатные тесты запускаются средствами проекта; `trace` читает поддерживаемые отчёты и не оценивает смысл сценария. Неподдерживаемый формат не отменяет действительное штатное доказательство.

Граница Поставки — Windows/source-only; стек подключаемого проекта определяется при init. Хуки, Covers, бинарные пакеты и другие платформы отложены.

## Условия готовности

[QUALITY](QUALITY.md) задаёт проверки самой Поставки, [CONTEXT](CONTEXT.md) — местный контекст. Установка, поведение навыков, публикация, активация и пользовательская приёмка подтверждаются отдельно. Ограниченный пилот завершён; новая работа в подключаемых проектах требует отдельного поручения.
