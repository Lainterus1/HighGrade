# Маршрут интерфейса спецификаций — архив

Этапы HG-0052–HG-0057 технически завершены. Полный маршрут сохранён [в архиве](../archive/plans/specification-ui-sequence.md) по исходному пути, на который ссылаются интегрированные спеки. Действующее поведение интерфейса описано в [UI](../UI.md) и уточнено HG-0058; прежние указания о переходах и остановке относятся к выполненной цепочке.
