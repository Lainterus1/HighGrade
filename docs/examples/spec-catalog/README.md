# Пример проектной спеки

[spec.json](spec.json) — русскоязычный пример сложения: цель, требование, сценарий, задачи и checks. В настоящем проекте файл лежит в specs/changes/HG-0001/spec.json (либо выбранном каталоге). Проверки и решения находятся в соседнем results.json; пример не переносит доказательства из тестового окружения.

Файл получен установленной изолированной CLI 0.2.14. Полный жизненный цикл и повторный прогон проверены; человеческая приёмка не записывалась.
