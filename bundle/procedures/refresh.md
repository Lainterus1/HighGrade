# Актуализация по запросу

Уточни область и режим. При запросе «проверь/проанализируй» режим только чтение: выполни общий аудит из `references/audit.md`, `doctor`/`inspect` из [активного exe](../references/cli.md) и применимые штатные команды, сравни архитектуру, OpenSpec, документы, временные обходы и архив с фактическим состоянием. Не исправляй файлы и не меняй бюджеты. Запиши проверенное, противоречия, размеры, непокрытые области и решение, которое действительно требуется.

При явном поручении исправлять актуализируй в его области с обычными проверками и обязательным ревью. Изменение диапазонов бюджетов — отдельное решение автора: покажи размеры, причину и последствия, не поднимай потолок автоматически. Архивируй подтверждённо заменённое по `procedures/archive.md`. Refresh — дополнительный обзор; обычная работа не ждёт его вызова. `highgrade update` отсюда не запускается.
