# Работа над задачей High Grade

Корень проекта — три каталога вверх от папки навыка. Прочитай и проверь `.highgrade/active.json`, затем `.highgrade/releases/<release>/rules.md` и `procedures/work.md`. Не подбирай поставку по последнему использованному терминалу. При отсутствующем или повреждённом подключении покажи состояние и останови только зависимую работу.

Выполняй процедуру на разрешённой области. Малые задачи допускают прямое выполнение по AGENTS; этот навык предназначен для задач с зависимыми этапами и продолжением. Не создавай дублирующий backlog поверх OpenSpec.
