# Обновление High Grade

Корень проекта — три каталога вверх от папки навыка. Проверь текущий `.highgrade/active.json` и прочитай `.highgrade/releases/<release>/procedures/update.md`. Используй только явно выбранный кандидатом исходный каталог, не ищи latest и не запускай обновление из refresh.

Покажи проверки до переключения. При конфликте или неудаче прежняя рабочая основа остаётся активной. Проектную адаптацию не переписывай.
