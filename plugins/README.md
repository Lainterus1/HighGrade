# Поддерживаемые плагины

Здесь находятся самостоятельные исходные пакеты. Пока они не распределены по функциональным направлениям и не подключены к общему workflow.

| Компонент | Назначение | Вход |
|---|---|---|
| SVG Vectorizer | Детерминированное преобразование растра в SVG | [README](svg-vectorizer/README.md), [навык](svg-vectorizer/skills/vectorize/SKILL.md) |
| Code Health Audit | Аудит поддерживаемости Python с проверяемыми данными анализаторов | [навык](code-health-audit/skills/code-health-audit/SKILL.md), [toolchain](code-health-audit/skills/code-health-audit/references/toolchain.md) |

Первоначальный перенос сохранил байты исходных пакетов, включая их тесты и исторические отчёты. Происхождение: [манифест](../docs/imports/plugins-import.json). Сам перенос не переключал установленные версии Codex. Новые изменения выполняются здесь; копии в старых исходных каталогах сохранены как база переноса, их не следует независимо развивать.

## Направление развития

По принятому [WF-RUST-01](../docs/archive/workflow/SPECIFICATION.md) собственные программы плагинов планируется постепенно переносить на Rust. Для каждого отдельно оцениваются польза, границы переноса, внешние зависимости и сохранение поведения. Порядок миграций ещё не выбран. По [WF-RELEASE-01](../docs/archive/workflow/SPECIFICATION.md) миграции не были условием первого выпуска и планируются отдельными этапами. Первоначальный перенос не переписывал исходники и не переключал установленные версии; язык реализации не меняет назначение плагина.
